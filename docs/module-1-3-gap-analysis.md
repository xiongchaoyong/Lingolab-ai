## 模块 1：用户注册与多维度画像 (P0)

### 需求采集字段

| 字段 | 需求 | 实现 | 状态 |
|------|------|------|:---:|
| username | 4-20 字符，字母数字下划线 | 无长度/格式校验 | ❌ |
| password | 8-32 字符，含字母+数字 | bcrypt 加密，但无复杂度校验 | ⚠️ |
| age | 输入实际年龄，拒绝 <1 或 >150 | 无异常值校验 | ❌ |
| learning_goal | 5 选 1 必填 | ✅ 已实现 | ✅ |
| interests | 多选选填 | ✅ 已实现 | ✅ |

### 验收标准

| # | 验收项 | 状态 |
|:---:|------|:---:|
| 1 | 用户名+密码可完成注册并自动登录 | ✅ |
| 2 | 重复用户名注册返回 409 错误 | ✅ |
| 3 | 密码 bcrypt 加密存储，数据库中不可逆 | ✅ |
| 4 | 年龄自动归类正确（覆盖 5 个区间边界值） | ✅ |
| 5 | 注册后首次登录强制跳转到测评页 | ✅ |
| 6 | 测评完成后 `assessment_completed` 变为 `true` | ✅ |
| 7 | **测评完成前无法访问首页/发音/对话功能** | ❌ |

### 边界情况

| 场景 | 需求 | 状态 |
|------|------|:---:|
| 用户名已存在 | 返回 409 | ✅ |
| 密码不符合规则 | 返回 422 | ❌ 未实现 |
| 注册后未完成测评直接关闭 | 下次登录强制跳转测评页 | ✅ |
| 测评中途退出 | 保存进度，恢复上次答题位置 | ❌ 未实现 |
| 年龄输入异常值 | 拒绝提交 | ❌ 未校验 |

### 关键缺失（按优先级排序）

| 优先级 | 模块 | 缺失项 | 影响 |
|:---:|:---:|------|------|
| **P0** | 模块 2 | 口语题真实评分（硬编码 60 分） | 测评结果不准确，无法区分用户口语水平 |
| **P0** | 模块 2 | 自适应难度调整 | 所有用户做同一套题，无法精准定级 |
| **P0** | 模块 1+2 | 测评完成前无路由守卫 | 用户可以跳过测评直接访问首页 |
| **P0** | 模块 2 | 题库仅 10 题 | 题目固定，重复测评无意义 |
| P1 | 模块 1 | 密码复杂度校验 | 安全性不足 |
| P1 | 模块 1 | 年龄异常值校验 | 数据质量 |
| P1 | 模块 2 | 测评中断恢复 | 用户体验差 |
| P1 | 模块 3 | 年龄归类影响内容 | 儿童和成人看到相同内容 |
| P2 | 模块 3 | 连续跳过智能提示 | 用户引导不足 |
| P2 | 模块 3 | 加量功能 | 高活跃用户无额外内容 |

### 需要立即修复的（P0 阻塞项）

1. **口语题评分**：对接 WhisperX + LLM 评分管线，替换硬编码 60 分
2. **自适应难度**：实现答对升/答错降的难度调整逻辑
3. **路由守卫**：`router.beforeEach` 中增加 `assessment_completed` 检查，未测评用户只能访问测评页
4. **题库扩充**：从 10 题扩展到至少 120 题（每难度每维度 5 题）
