# 发音评测 — 五维评分功能说明

> 整理自 2026-06-05 XCY 与 Claude Code 的讨论记录

---

## 一、功能概述

用户跟读标准发音后，系统从五个维度进行精细评分，通过音素级对比展示发音问题，并生成针对性纠音练习。

---

## 二、五维评分维度

### 1. 音素准确度（你在说哪个音）

检查每个音标是否读对。

| 示例 | 标准发音 | 常见错误 |
|------|----------|----------|
| "think" | /θɪŋk/ | `/sɪŋk/` — th 读成 s |
| "rice" | /raɪs/ | `/laɪs/` — r 读成 l |

**技术方案**（当前已实现 v1）：
- wav2vec2 + CTC 强制对齐 → GOP 算法
- 计算每个字符的后验概率 → 0-100 分数
- **局限**：v1 为字符级评分（A-Z），非真音素（IPA），后续需升级

### 2. 重音位置（你在哪个音节用力）

英语是重音计时语言，重音错了母语者会听不懂。

| 示例 | 说明 |
|------|------|
| `DESert` vs `deSSERT` | 重音不同 = 完全不同的词（沙漠 / 甜点） |
| `PHOtograph` → `phoTOgrapher` | 词形变化时重音跟着变 |

**技术方案**（待实现）：
- 音频能量包络 — `librosa.feature.rms()` 提取每帧能量
- 时长特征 — GOP 对齐已有 `duration_ms`，重读音节通常更长
- F0 基频 — 重读音节音高更高
- 与 G2P 输出的预期重音位置对比打分
- **难度**：中

### 3. 连读表现（你有没有把词连起来说）

母语者说话时会把词粘在一起，不是逐个蹦词。

| 原文 | 实际读法 | 连读类型 |
|------|----------|----------|
| "What are you doing?" | "Whaddaya doin?" | 辅元连读 + 弱化 |
| "not at all" | "no-ta-tall" | 辅元连读 t→a |
| "I like it" | "I li-kit" | 辅元连读 k→i |

**技术方案**（待实现）：
- 检测相邻词边界是否存在辅音-元音连读条件
- 对词边界音频段提取特征，判断是否发生连读
- 与预期连读规则对比打分
- **难度**：高，需专门模型或复杂启发式规则，建议 P2

### 4. 语调曲线（你的声音是往上走还是往下走）

同样的话，音调走向不同，意思不同。

| 句子 | 语调 | 含义 |
|------|------|------|
| "You're coming." | ↘ 降调 | 陈述事实 |
| "You're coming?" | ↗ 升调 | 提出疑问 |
| "YOU're coming?" | ↗↘ 强调 | 强调是**你**来 |

**技术方案**（待实现）：
- `librosa.pyin()` 提取 F0 基频曲线
- 线性拟合 F0 曲线得到整体趋势（升/降/平）
- 根据句子类型匹配预期模式：陈述→降、疑问→升
- 比较实际语调与预期模式的相似度
- **难度**：中

### 5. 节奏感（你的音素时长是不是均匀的）

流利者音素时长有规律可循，不会忽快忽慢或异常卡顿。

```
学习者：I...  [卡顿300ms]  like...  [卡顿200ms]  to...  play
流利者：I-like-to-play  连贯通畅
```

**技术方案**（待实现）：
- CTC 对齐已有每个音素的 `duration_ms` 数据
- 计算音素时长标准差 → 越均匀节奏越好
- 检测异常停顿（duration > 2x 均值）
- 与英语 stress-timed 自然节奏对比
- **难度**：低（数据已就位）

## 六、一句话总结

| 维度 | 通俗理解 |
|------|----------|
| 音素准确度 | 每个音发对没？ |
| 重音位置 | 该重的地方重了没？ |
| 连读表现 | 词和词粘起来了没？ |
| 语调曲线 | 声调走势对了没？ |
| 节奏感 | 节拍稳定不卡顿？ |
