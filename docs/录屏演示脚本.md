# Lingolab-ai 录屏演示脚本

> 预计总时长：15-20 分钟
> 演示账号：见各场景开头
> 建议分辨率：1920×1080，浏览器 Chrome 全屏

---

## 前置准备

```bash
# 1. 启动数据库（确保 MySQL 运行，english_training_dev 库已初始化）
mysql -u root -p < backend/sql/init.sql

# 2. 导入种子数据
cd backend
python seed_assessment.py      # 测评题库 30 题
python seed_kg.py              # 知识图谱 129 节点 + 292 边
python seed_content.py         # 跟读内容库
python seed_module4.py         # 游戏化内容
python seed_module5.py         # 社区数据
python seed_module6.py         # 教师/管理员/班级/作业
python seed_feedback.py        # 反馈数据

# 3. 启动后端
uvicorn main:app --reload --port 8000

# 4. 启动前端
cd frontend && npm run dev
```

## 第二幕：核心学习链路（6 分钟）

> 模块 3：个性化学习路径
> 模块 4：AI 发音评测
> 模块 6：智能语音对话
> 模块 7：AI 语法纠错

### 2.1 学习路径（每日任务）

- 操作：导航栏点击「学习路径」
- 预期：展示今日 3 个任务卡片（跟读+对话+听力），每张卡片有标题、类型图标、预计时长
- 操作：点击某个任务的「换一个」按钮
- 预期：任务内容更新为新的推荐
- 操作：点击「调整难度」选择「更简单」
- 预期：任务难度降低
- 旁白：「系统根据 CEFR 等级和薄弱维度，每天自动生成个性化学习任务」

### 2.2 发音评测

- 操作：导航栏点击「学习中心」→「发音评测」
- 预期：展示跟读内容列表，可选单词/句子模式
- 操作：选择一个句子，点击录音按钮朗读
- 预期：录音完成后展示五维评分（音素准确度/重音/连读/语调/节奏）+ 综合分
- 操作：点击「查看详细评分」
- 预期：弹窗展示 5 个 Tab（逐音素评分/重音能量/F0 曲线/连读词对/节奏时长），含可视化图表
- 操作：点击「标准发音对比」播放标准音
- 预期：并排播放你的录音和标准发音
- 旁白：「发音评测基于 wav2vec2 模型，从五个维度给出专业评分，支持逐音素级别的纠错建议」

### 2.3 AI 智能对话

- 操作：导航栏点击「学习中心」→「AI 对话」
- 预期：展示场景选择（餐厅/酒店/机场/购物）
- 操作：选择「餐厅点餐」场景，点击「开始对话」
- 预期：AI 用英语开场白，底部显示录音按钮
- 操作：点击录音说一句英语（如 "I'd like a table for two, please"）
- 预期：展示 AI 回复 + 实时语法纠错卡片（如有错误）+ 流利度评分
- 操作：继续 3-4 轮对话
- 预期：每轮都有 AI 回复 + 语法纠错提示
- 操作：点击「结束对话」
- 预期：展示综合评分报告（发音30%+语法30%+词汇20%+参与度20%）+ 流利度五维报告 + 对话记录
- 旁白：「AI 对话支持实时语法纠错，结束后给出双层评分报告」

### 2.4 语法纠错（独立功能）

- 操作：导航栏点击「语法纠错」
- 预期：展示文本输入框 + 语音输入按钮
- 操作：在文本框输入 "He go to school yesterday and goed very fast"
- 预期：展示纠错结果 — 差异高亮（红色标记错误、绿色标记修正）+ 错误类型标签（时态/词形）+ 润色建议
- 操作：切换到语音模式，录一段有语法错误的英语
- 预期：ASR 转写后同样展示纠错结果
- 旁白：「语法纠错支持文本和语音两种输入，能检测 6 类常见语法错误并给出润色建议」

## 附录：演示注意事项

1. **录屏工具**：推荐 OBS Studio，分辨率 1920×1080，帧率 30fps
2. **语速**：每个操作间留 1-2 秒停顿，让观众看清界面
3. **鼠标**：开启鼠标高亮效果（如 PointerFocus），方便观众跟随
4. **网络**：确保后端 LLM/ASR 服务可用，提前测试一遍各 API
5. **备用方案**：如果 LLM 响应慢，可以提前截图/录屏备用片段
6. **浏览器**：使用 Chrome 无痕模式，避免插件干扰，书签栏隐藏
7. **账号准备**：提前注册好 demo_user，避免录屏时注册等待
