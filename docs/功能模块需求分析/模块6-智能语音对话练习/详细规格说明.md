# 模块 6：智能语音对话练习 — 详细规格说明

> P0 | 5 子功能 | 流程图 2 张 | 用例图：模块6-用例图.drawio

---

## (1) 对话场景选择与开场

### 需求

- 用户从4个MVP场景选择（自我介绍A1-B1/问路指路A2-B2/购物A2-B2/餐厅A1-B2）
- AI按CEFR生成开场白，文字气泡+TTS语音双模态展示。后续扩展至60+场景。

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| user_id | int | ✅ | JWT解析 |
| scene_id | int | ✅ | 1-4 |
| cefr_level | string | — | 未测评默认B1 |

### 处理

1. 校验场景可用性（用户CEFR在支持范围内）→ 构建System Prompt注入角色+CEFR+场景
2. Deepseek生成开场白 → Edge TTS合成语音 → 创建conversation记录 → 返回

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| conversation_id | UUID | 会话ID |
| ai_message | object | {text, audio_url, round_number:1} |
| scene_info | object | {scene_name, difficulty_range} |

**接口：** `POST /api/conversation/start`

## (2) 语音对话闭环引擎

### 需求

- 核心链路：录音→上传→Whisper转写→Deepseek生成→TTS合成→文字+语音双模态展示
- 端到端<3s（上传<0.5s+Whisper<1s+Deepseek<1s+TTS<0.5s）
- 每轮自动触发模块5(流利度)+模块7(语法纠错)

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| conversation_id | UUID | ✅ | 会话ID |
| audio_file | file | ✅ | 1-60s，≤3MB |
| round_number | int | ✅ | 当前轮次 |

### 处理

1. 音频校验（同模块4子功能2）→ 静音+超5s→AI主动提示
2. Whisper转写→低置信度标注确认 / 中文检测→"Say it in English"
3. 构建Prompt（System+10轮历史+当前输入）→ Deepseek生成（超时→应急回复库4条预设）
4. TTS合成（失败→仅文字+标注）→ 存储→触发模块5+7

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| ai_message_id | 前端 | int | 消息ID |
| ai_text | 前端 | string | AI回复文字 |
| ai_audio_url | 前端 | string | TTS语音URL，失败null |
| transcript | 前端+DB | string | 用户转写文本 |
| tts_unavailable | 前端 | bool | TTS失败标记 |

**接口：** `POST /api/conversation/{id}/speak` (multipart/form-data)

## (3) 对话上下文与记忆管理

### 需求

- 保留最近10轮上下文（用户转写+AI回复+语法纠错），同场景保持角色连贯，切换场景清除

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| conversation_id | UUID | ✅ | 会话ID |
| user_id | int | ✅ | JWT解析 |

### 处理

1. 每轮后自动追加消息到conversation_messages（role: user/ai/system）
2. 构建Prompt时取最近10条(5组对话)→ORDER BY round_number DESC LIMIT 20
3. 切换场景→旧conversation标记paused→创建新会话
4. 静默>5s→AI主动提示(系统消息不计轮次)

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| context_rounds | int | 当前上下文轮数 |
| is_paused | bool | 是否有可恢复会话 |

**接口：** `GET /api/conversation/{id}/context`

## (4) 难度自适应控制

### 需求

- 按CEFR调整4维参数注入Prompt。连续3轮错误率>30%→降级，连续5轮<10%→升级。边界保护A1/C2。

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| cefr_level | string | ✅ | user_profiles.level_final |
| recent_error_rates | array | ✅ | 模块7近5轮错误率 |
| conversation_id | UUID | ✅ | 会话ID |

### 处理

1. 查表获取当前CEFR四维参数：
   - A1-A2: vocab 500-1000 / 慢120wpm / 1-2句 / 每轮纠错
   - B1: vocab 1500-2500 / 正常150wpm / 2-3句 / 每3轮1次
   - B2+: vocab 3000+ / 快170wpm / 3-5句 / 仅明显错误
2. avg(last 3 errors)>0.30 → difficulty_level -= 1
3. avg(last 5 errors)<0.10 → difficulty_level += 1
4. clamp(A1, C2) → 注入下一轮Prompt

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| effective_difficulty | string | 当前生效难度(A1-C2) |
| vocab_level/speed/reply_len/correction_freq | — | 四维参数值 |

## (5) 对话结束综合评分

### 需求

- 对话结束(5-8轮后)触发，四维加权：发音30%+语法30%+词汇20%+参与度20%→综合分0-100

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| conversation_id | UUID | ✅ | 会话ID |
| user_id | int | ✅ | JWT解析 |

### 处理

1. 查询conversation_messages所有轮评分 → 过滤无效
2. 发音分=AVG(每轮pronunciation_score)×0.30
3. 语法分=(1-AVG(error_rate))×100×0.30
4. 词汇分=Deepseek评估(TTR+多样性)×0.20
5. 参与度=(avg_reply_words归一化+主动提问率)×0.20

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| total_score | int | 0-100 |
| dimension_scores | object | {pronunciation,grammar,vocabulary,engagement} |
| total_rounds | int | 对话轮数 |
| highlights | array | 亮点总结 |

**接口：** `POST /api/conversation/{id}/end`
