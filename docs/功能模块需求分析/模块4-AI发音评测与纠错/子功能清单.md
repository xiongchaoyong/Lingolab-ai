# 模块 4：AI 发音评测与纠错 — 子功能清单

> 优先级：P0 | 参考 PRD：模块 4

- (1) **跟读内容选择与展示** — 用户自由切换单词模式（展示单词+IPA 音标+标准音播放）和句子模式（展示完整句子+标准音播放），系统根据 CEFR 等级默认推荐对应难度内容，支持先听后读
- (2) **语音录制与上传** — 用户点击录音按钮跟读标准内容，前端采集音频（采样率 ≥16kHz）并上传至后端，后端校验音频有效性（静音检测/时长/大小），异常时提示重录（最多 1 次）
- (3) **发音多维度评分引擎** — 调用 Whisper API 进行音素级对齐，逐音素对比标准发音，计算五维分数（单词模式：音素 50%+重音 25%+节奏 25%；句子模式：音素 40%+重音 15%+连读 15%+语调 15%+节奏 15%），输出综合分 0-100，单次评测延迟 < 3s
- (4) **错误音素定位与纠音建议** — 定位用户发音中与标准音素不匹配的具体位置（如 `th /θ/ → /s/`），对每个错误音素生成中文纠音方法文字建议（如「舌尖轻触上齿，气流从齿缝挤出」），展示标准 IPA 音标作为参考
- (5) **跟读内容库管理** — 运营人员后台对跟读内容（单词+句子）的增删改查，按 CEFR 难度（A1/B1/B2+）和模式分类管理，每条内容包含标准文本、标准音频文件、IPA 音标、音素标注序列；MVP 阶段总量 ≥ 440 条（单词 340 + 句子 190）
