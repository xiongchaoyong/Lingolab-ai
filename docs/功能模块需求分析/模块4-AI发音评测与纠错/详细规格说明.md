# 模块 4：AI 发音评测与纠错 — 详细规格说明

> P0 | 5 子功能 | 流程图 2 张 | 用例图：模块4-用例图.drawio

---

## (1) 跟读内容选择与展示

### 需求

- 用户切换单词/句子双模式，系统按CEFR推荐内容。展示文本+IPA音标+标准音播放按钮，支持先听后读。

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| user_id | int | ✅ | JWT解析 |
| mode | enum | ✅ | word/sentence |
| cefr_level | string | ✅ | 来自user_profiles.level_final |

### 处理

1. 查内容库 WHERE mode+CEFR → 排除最近3次练习 → 按last_practiced_at ASC（最久未练优先）
2. 返回top1：文本+IPA+标准音频URL

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| content_id | int | 内容ID |
| content_text | string | 单词或句子文本 |
| ipa_notation | string | IPA音标 |
| audio_url | string | 标准音播放URL |

**接口：** `GET /api/pronunciation/next-content?mode=word`

---

## (2) 语音录制与上传

### 需求

- 浏览器录音(≥16kHz单声道)→上传→后端校验(格式/静音/时长/大小)。无效→提示重录限1次；有效→存储返回audio_id。

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| audio_file | file | ✅ | wav/webm，单词1-10s/句子2-30s，≤3MB |
| content_id | int | ✅ | 对应标准内容 |
| mode | enum | ✅ | word/sentence |

### 处理

1. 校验格式(WAV/WebM) → 静音检测(RMS<0.005) → 时长校验(单词≥1s/句子≥2s)
2. 无效+未重录→422提示重录 / 无效+已重录→标记0分 / 有效→存储→返回audio_id

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| audio_id | UUID | 评分引擎输入 |
| audio_duration | float | 录音时长(秒) |
| validation_status | enum | valid/silent/too_short |

**接口：** `POST /api/pronunciation/upload-audio` (multipart/form-data)

---

## (3) 发音多维度评分引擎

### 需求

- Whisper音素级对齐→五维评分→综合分0-100→颜色标注(≥80绿/60-79黄/<60红)。单词模式权重50-25-25，句子模式40-15-15-15-15。延迟<3s。

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| audio_id | UUID | ✅ | 子功能(2)输出 |
| content_id | int | ✅ | 用于获取标准音素序列 |
| mode | enum | ✅ | word/sentence |

### 处理

1. 获取标准内容：音频+音素序列+IPA
2. Whisper API 音素级转写（timestamp_granularities=["word","phoneme"]）→ 解析音素+置信度
3. 转写vs标准文本对比 → 不匹配→标记warning
4. DTW音素对齐（用户音素↔标准音素）
5. 逐维计算：音素准确度（逐位对比）、重音（能量峰值偏差）、连读（仅句子，边界音素连接率）、语调（仅句子，F0 Pearson系数）、节奏（KL散度）
6. 按模式加权：word=50-25-25 / sentence=40-15-15-15-15

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| total_score | 前端+DB | int | 0-100 |
| phoneme_accuracy | 前端 | int | 0-100 |
| stress_accuracy | 前端 | int | 0-100 |
| linking_score | 前端 | int | 句子模式，单词null |
| intonation_score | 前端 | int | 句子模式，单词null |
| rhythm_score | 前端 | int | 0-100 |
| color_label | 前端 | enum | green/yellow/red |
| transcript | 前端 | string | 转写文本 |
| confidence | 前端 | float | 0-1 |

**接口：** `POST /api/pronunciation/score`

## (4) 错误音素定位与纠音建议

### 需求

- 基于音素对齐定位错误音素（替换/遗漏/插入）→ 查纠音模板库(30+条)生成中文建议 → 错误红色高亮+IPA参考

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| score_result | object | ✅ | 子功能(3)完整评分结果 |
| content_id | int | ✅ | 标准内容ID |

### 处理

1. 遍历音素对齐结果 → 筛选 user_phone ≠ ref_phone 的对
2. 按置信度升序（低=更严重）→ 查纠音模板库匹配建议
3. 拼接错误标注文本 → 错误音素红色高亮

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| error_count | 前端 | int | 错误总数 |
| errors[] | 前端 | array | [{position,user_phone,ref_phone,error_type,advice,confidence}] |
| annotated_text | 前端 | HTML | 错误红色高亮标注 |

## (5) 跟读内容库管理

### 需求

- 运营后台CRUD，按CEFR+模式管理。每条含文本/标准音频/IPA音标/音素序列。MVP≥530条(单词340+句子190)。

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| content_text | string | ✅ | 1-200字符 |
| mode | enum | ✅ | word/sentence |
| difficulty | enum | ✅ | A1/A2/B1/B2+ |
| audio_file | file | ✅ | MP3/WAV ≤2MB |
| ipa_notation | string | ✅ | IPA音标 |
| phoneme_sequence | string | ✅ | 空格分隔标准音素序列 |

### 处理

1. 校验权限(operator/admin) → 校验格式(音素仅允许IPA标准符号) → 上传音频 → 创建/更新记录
2. 删除 → 软删除(is_deleted=true)，保留历史评测记录

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| content_id | int | 内容ID |
| content_text/mode/difficulty | — | 内容属性 |
| audio_url | string | 音频地址 |

**接口：** `GET/POST/PUT/DELETE /admin/pronunciation-content`
