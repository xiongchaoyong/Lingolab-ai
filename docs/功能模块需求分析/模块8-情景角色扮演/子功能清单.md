# 模块 8：情景角色扮演 — 子功能清单

> 优先级：P2 | 参考 PRD：模块 8

- (1) **角色与场景选择** — 用户从 3 个 MVP 角色中选择（面试者/餐厅服务员/导游），对话前展示角色说明卡（角色目标、场景描述、常见用语、建议话术），帮助用户理解角色定位和预期表达方式
- (2) **角色扮演对话引擎** — 完全复用模块 6 语音对话闭环技术链路（录音→Whisper→Deepseek→TTS），差异在于 System Prompt 注入角色设定（AI 角色+场景描述+用户角色+评估维度），AI 扮演对方角色进行多轮互动（面试官/顾客/游客），用户偏离角色时 AI 温和拉回
- (3) **角色贴合度四维评分** — 对话结束评分体系不同于模块 6：角色贴合度 40%（表达是否符合角色身份和场景）+ 场景礼仪 25%（敬语/称呼/语气是否得体）+ 专业术语 20%（场景相关词汇使用准确性）+ 应对能力 15%（面对突发问题的恰当回应），输出综合评分和改进建议
- (4) **角色场景内容管理** — 运营后台管理角色定义（角色名称、AI 角色、场景描述、难度范围）、角色说明卡内容（角色目标/常见用语/建议话术）、评分权重配置；后续迭代扩展至更多角色场景
