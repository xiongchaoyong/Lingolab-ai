# 模块 8：情景角色扮演 — 详细规格说明

> P2 | 4 子功能 | 流程图 1 张 | 用例图：模块8-用例图.drawio

---

## (1) 角色与场景选择

### 需求

- 用户从3个MVP角色选择：面试者(AI面试官)/餐厅服务员(AI顾客)/导游(AI游客)
- 对话前展示角色说明卡（角色目标+场景+常见用语5-8句+建议话术2-3条）

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| user_id | int | ✅ | JWT解析 |
| role_id | int | ✅ | 1=面试者/2=服务员/3=导游 |
| cefr_level | string | — | 用于难度提示 |

### 处理

1. 查询角色定义→CEFR校验(低于难度范围→提示不禁止)→返回角色信息+说明卡

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| role_info | object | {role_name,ai_role,scene_description,difficulty_range} |
| briefing_card | object | {goal,common_phrases[],strategy_tips[]} |
| difficulty_warning | string | CEFR偏低时提示 |

**接口：** `GET /api/roleplay/roles/{id}`

---

## (2) 角色扮演对话引擎

### 需求

- 100%复用模块6语音对话闭环（录音→Whisper→Deepseek→TTS），差异在System Prompt注入角色设定+评估维度
- AI扮演对方角色，用户偏离时温和拉回，角色卡结束自然收尾

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| conversation_id | UUID | ✅ | 会话ID |
| audio_file | file | ✅ | 同模块6 |
| role_id | int | ✅ | 角色ID |
| cefr_level | string | ✅ | 用户CEFR |

### 处理

1. 同模块6子功能(2)全流程
2. Prompt差异：注入角色设定 `You are {ai_role} in "{scene}". User plays {user_role}. Evaluate: role authenticity/etiquette/terminology/adaptability.`
3. 偏离检测：连续2轮→温和提醒 / 3轮→"Let's get back to our roles..."
4. 自然结束：面试→"We'll be in touch" / 餐厅→"The bill please" / 导游→"Thank you"

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| ai_message | object | 同模块6 + role_deviation_warning + scene_ending_signal |

---

## (3) 角色贴合度四维评分

### 需求

- 对话结束触发，四维体系：角色贴合度40%+场景礼仪25%+专业术语20%+应对能力15%→综合分0-100+各维评语

### 输入

| 字段 | 类型 | 说明 |
|------|------|------|
| conversation_id | UUID | 会话ID |
| role_id | int | 角色ID |

### 处理

1. 获取全对话记录→构造角色评分Prompt→Deepseek四维评估
2. 加权：贴合度×0.40+礼仪×0.25+术语×0.20+应对×0.15
3. <3轮→不评分 / Deepseek超时→降级仅角色贴合度其余N/A

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| total_score | int | 0-100 |
| dimension_scores | object | {role_authenticity,scenario_etiquette,professional_terms,adaptability} |
| feedback | object | {per_dimension[],overall_tip} |

**接口：** `POST /api/roleplay/{conversation_id}/evaluate`

## (4) 角色场景内容管理

### 需求

- 运营后台管理角色定义+说明卡+评分权重配置(默认40/25/20/15可调)。P2阶段3角色，后续扩展。

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| role_name | string | ✅ | 角色名称 |
| ai_role | string | ✅ | AI扮演角色名 |
| user_role | string | ✅ | 用户扮演角色名 |
| scene_description | string | ✅ | 场景描述 |
| difficulty_range | string | ✅ | A1-C2范围如"B1-B2" |
| briefing_card | JSON | ✅ | {goal,common_phrases[],strategy_tips[]} |

### 处理

- 标准CRUD（同模块2题库管理）→ 删除=软删除保留历史

### 输出

- role_id, role_name, ai_role, user_role, created_at

**接口：** `GET/POST/PUT/DELETE /admin/roleplay-roles`
