# 模块 7：AI 语法纠错与润色 — 详细规格说明

## (1) 语法错误检测与定位

### 需求

- 嵌入模块6每轮对话，Deepseek检测6类语法错误（时态/主谓一致→高;冠词/介词/单复数→中;词序→低），返回错误词位置+类型+修正

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| transcript | string | ✅ | Whisper转写文本 |
| conversation_id | UUID | ✅ | 会话ID |
| round_number | int | ✅ | 对话轮次 |
| whisper_confidence | float | ✅ | 转写置信度 |

### 处理

1. 词数检查：<3词→标记too_short不纠错
2. 构造Prompt（语法+润色联合，一次API调用）→ Deepseek → 解析errors数组
3. 低置信度→标注"纠错仅供参考" / API格式异常→不展示+记录日志
4. 写入conversation_messages.grammar_check

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| error_count | int | 错误总数 |
| errors[] | array | [{word,correction,type,position[start,end]}] |
| too_short | bool | <3词 |
| low_confidence | bool | 转写置信度低 |

## (2) 地道表达润色建议生成

### 需求

- 同一次API调用同时生成润色建议，5类：礼貌升级/口语自然化/俚语习语/缩略自然化/冗余精简
- 默认折叠，点击"💡更地道的说法"展开；用户采纳→记录偏好

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| transcript | string | ✅ | 同子功能(1) |
| scene_context | string | — | 模块6场景，正式场景过滤俚语 |
| cefr_level | string | — | 控制润色复杂度 |

### 处理

1. 与子功能(1)共用一次Deepseek调用（Prompt同时请求grammar+polish）
2. 解析polish_suggestion → 场景适配过滤 → 返回
3. 采纳→conversation_messages.grammar_check.polish_adopted=true → 累计偏好

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| polish_suggestion | string | 润色版文本，null=无需润色 |
| polish_type | enum | politeness/casual/idiom/contraction/conciseness |
| original_preserved | bool | 原文已很地道 |

## (3) 纠错结果展示与用户交互

### 需求

- 对话气泡展示：原文错误红色波浪线+修正版绿色+每条中文语法说明
- 润色折叠可展开+采纳按钮。无错误→✅"This sounds good!"。<3词→"建议展开表达"

### 输入

| 字段 | 类型 | 说明 |
|------|------|------|
| grammar_result | object | 子功能(1)+(2)联合输出 |
| user_preferences | object | 是否关闭纠错展示 |

### 处理

1. 错误按权重降序→>5个仅展示前5其余折叠
2. 渲染原文HTML（错误词<mark class="error">标注）+ 修正版 + 语法说明
3. 润色区：polish_suggestion非null→渲染折叠面板+采纳按钮

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| html_snippet | HTML | 前端气泡渲染 |
| error_summary | string | "N个语法错误"或"✅" |
| polish_available | bool | 是否展示润色区 |

---

## (4) 常见错误汇总与频次统计

### 需求

- 对话结束汇总Top 3高频错误+改进建议。历史写入grammar_error_log，7天内同类型不重复推送。

### 输入

| 字段 | 类型 | 说明 |
|------|------|------|
| conversation_id | UUID | 会话ID |
| user_id | int | JWT解析 |

### 处理

1. 查询conversation_messages所有grammar_check → 合并errors → 按type分组计数→降序Top3
2. 查表匹配改进建议（tense→"注意动词时态" / agreement→"注意主谓一致" / article→"注意冠词"...）
3. 写入grammar_error_log（去重：同user+同type 7天内不重复推送）

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| top_errors[] | array | [{type,count,suggestion}] |
| total_errors | int | 总错误数 |
| no_errors | bool | 无错误→展示正面反馈 |

**接口：** `GET /api/grammar/report/{conversation_id}` `GET /api/grammar/history?days=30`
