## (1) 自适应题目推送引擎

### 需求

- 根据自评等级确定初始 CEFR 难度起点，每题后动态调整（答对+0.5级/答错-0.5级/口语0分不变）
- 交错推送 10 题（听力3+口语2+阅读3+语法2），全对追加C2确认题，全错追加A1兜底题

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| user_id | int | ✅ | JWT解析 |
| level_self | string | ✅ | 初级/中级/高级→CEFR起点 |
| assessment_session_id | UUID | ✅ | 会话ID，30min过期 |
| current_question_index | int | — | 当前题号，0=首题 |
| last_answer_result | object | — | {question_id, is_correct, score} |

### 处理

1. 首题请求 → 读取 level_self 映射 CEFR 起点（初级→A1/中级→B1/高级→B2）→ 创建会话
2. 后续请求 → 解析 last_answer：答对 +0.5、答错 -0.5、口语0分不变 → clamp[1.0,6.0]
3. 满10题 → 全对追加C2/全错追加A1/否则返回 assessment_complete
4. 未满10题 → 按题序模板[听,语,阅,口,听,阅,语,听,阅,口]确定下一维度 → 按难度+维度查题库（无匹配降级查找C2→...→A1）
5. 返回题目数据 + 更新会话状态

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| question_id | 前端 | int | 题目ID |
| question_text | 前端 | string | 题目内容 |
| question_type | 前端 | enum | listening/speaking/reading/grammar |
| options | 前端 | array | 客观题选项，口语题为null |
| question_index | 前端 | int | 第几题(1-11) |
| is_last_question | 前端 | bool | 是否最后一题 |
| assessment_complete | 前端 | bool | 测评是否完成 |

**接口：** `GET /api/assessment/next-question` `POST /api/assessment/submit-answer`

## (2) 客观题作答与自动判分

### 需求

- 听力（听对话选答案，音频可播3次）/ 阅读（完形填空/阅读理解）/ 语法（时态语态句型选择）
- 用户提交答案 → 后端对比题库 correct_answer → 返回对错

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| question_id | int | ✅ | 题目ID |
| selected_answer | string | ✅ | A/B/C/D |
| assessment_session_id | UUID | ✅ | 会话ID |

### 处理

1. 校验会话状态 + 题目一致性（防止重复提交→409）
2. 查题库 correct_answer → 对比 selected_answer → is_correct = (两者相等)
3. 客观题 score = is_correct ? 100 : 0
4. 记录结果 → 触发自适应引擎 → 返回判分

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| is_correct | 前端+引擎 | bool | 正确/错误 |
| correct_answer | 前端 | string | 正确答案（答题后展示） |
| score | 引擎+报告 | int | 0或100 |

**接口：** `POST /api/assessment/submit-answer`

## (3) 口语题录音与 AI 评分

### 需求

- 展示话题→15s准备→30-60s录音→Whisper转写→Deepseek四维评分（内容/语法/词汇/连贯各0-25→总分0-100）

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| assessment_session_id | UUID | ✅ | 会话ID |
| question_id | int | ✅ | 口语题ID |
| audio_file | file | ✅ | wav/webm，5-60s，≤5MB，≥16kHz |
| retry_flag | bool | — | 是否重录（限1次） |

### 处理

1. 校验音频（格式/大小/静音检测 RMS<0.005→静音/时长<5s→过短）
2. 无效且未重录 → 422提示重录 / 无效且已重录 → 标记0分跳过
3. 有效 → Whisper API 转写（超时重试1次）→ 构造评分Prompt → Deepseek评分（超时重试1次）
4. 存储：transcript + 四维分 + total_score → conversation_messages

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| transcript | 前端+DB | string | 转写文本 |
| content_relevance | 前端 | int | 0-25 |
| grammatical_accuracy | 前端 | int | 0-25 |
| lexical_richness | 前端 | int | 0-25 |
| logical_coherence | 前端 | int | 0-25 |
| total_score | 前端+引擎 | int | 0-100 |
| brief_feedback | 前端 | string | 中文短评 |

**接口：** `POST /api/assessment/submit-speaking` (multipart/form-data)

## (4) 测评进度保存与断点恢复

### 需求

- 每题后自动持久化已答数据+自适应状态；中途退出后下次登录检测未完成会话→恢复断点；30min无活动过期

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| user_id | int | ✅ | JWT解析 |
| action | enum | ✅ | check/resume/start |

### 处理

1. 前端加载测评页 → check API → 查询 status='in_progress' 会话
2. 无会话 → 返回 has_pending=false → 开始新测评
3. 有会话 → 检查 updated_at：≤30min → 返回会话信息+已答题数 / >30min → 标记 expired
4. 用户选择恢复 → resume API → 恢复当前难度+进度 → 返回下一题
5. 每题作答后自动触发 save → 写入 answered_questions + 更新 current_difficulty

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| has_pending | 前端 | bool | 是否有未完成会话 |
| session_id | 前端 | UUID | 恢复用 |
| answered_count | 前端 | int | 已答题数 |
| next_question | 前端 | object | 恢复后的下一题（同(1)输出） |

**接口：** `GET /api/assessment/session/check` `POST /api/assessment/session/resume`

## (5) 测评报告生成与展示

### 需求

- 汇总10题→计算CEFR等级+四维能力分→生成报告（等级标签+四维条形图+短板定位+学习建议）
- 更新 user_profiles.level_final + assessment_completed=true

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| assessment_session_id | UUID | ✅ | 已完成状态的会话 |
| user_id | int | ✅ | JWT解析 |

### 处理

1. 按维度分组统计正确率（听力/阅读/语法=正确数/总题数×100，口语=total_score均值）
2. 综合分 = 四维均值；CEFR映射：0-20→A1/21-40→A2/41-60→B1/61-80→B2/81-95→C1/96-100→C2
3. 取最后3题平均难度作稳定参考（相差>1级取稳定值）
4. 短板定位：分数 ≤ min_score+10 的维度 / 颜色：≥80绿/60-79黄/<60红
5. Deepseek生成学习建议（超时→预设模板）→ 更新user_profiles → 写入assessment_results

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| cefr_level | 前端+DB | string | A1-C2 |
| total_score | 前端 | int | 0-100 |
| dimension_scores | 前端 | object | {listening,speaking,reading,grammar} |
| weakness_dimensions | 前端 | array | 短板维度列表 |
| learning_advice | 前端 | string | 中文学习建议 |

**接口：** `POST /api/assessment/generate-report` `GET /api/assessment/report/{id}`

## (6) 测评题库管理

### 需求

- 运营后台CRUD，按维度+CEFR等级管理。每题含题目文本/选项/正确答案/难度标记，听力题含音频。MVP≥120题（每难度每维度≥5题），支持CSV批量导入。

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| question_text | string | ✅ | 1-500字符 |
| question_type | enum | ✅ | listening/speaking/reading/grammar |
| difficulty | enum | ✅ | A1/A2/B1/B2/C1/C2 |
| options | array | — | 2-4选项（口语题不需要） |
| correct_answer | string | — | A/B/C/D（口语题不需要） |
| audio_url | string | — | 听力题必填 |

### 处理

1. 校验权限（operator/admin）→ 校验字段 → 增/改/删
2. 批量导入：逐行解析CSV/JSON → 校验 → 成功行插入/失败行收集错误明细
3. 删除 → 软删除（is_deleted=true），保留历史测评记录

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| question_id | 前端+DB | int | 题目ID |
| question_text/type/difficulty | 前端 | — | 题目属性 |

**接口：** `GET/POST/PUT/DELETE /admin/questions` `POST /admin/questions/batch-import`
