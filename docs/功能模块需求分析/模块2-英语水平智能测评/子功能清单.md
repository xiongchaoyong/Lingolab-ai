# 模块 2：英语水平智能测评 — 子功能清单

> 优先级：P0 | 参考 PRD：模块 2

- (1) **自适应题目推送引擎** — 根据用户自评等级确定初始 CEFR 难度起点，每题作答后动态调整下一题难度（答对 +0.5 级、答错 -0.5 级），按交错题序（非分块）推送听力/口语/阅读/语法四维度共 10 题
- (2) **客观题作答与自动判分** — 听力（听短对话选正确答案）、阅读（完形填空/阅读理解）、语法（时态/语态/句型选择题）三类客观题的题目展示、用户作答提交、与正确答案自动对比并返回判分结果
- (3) **口语题录音与 AI 评分** — 展示口语话题 → 15 秒准备倒计时 → 30-60 秒录音 → Whisper API 转写为文本 → Deepseek 对转写文本四维评分（内容相关性 0-25 + 语法正确性 0-25 + 词汇丰富度 0-25 + 逻辑连贯性 0-25），输出总分 0-100
- (4) **测评进度保存与断点恢复** — 每题作答后实时持久化已答题目、答案、得分及当前自适应状态；用户中途退出（关闭页面/网络断开）后下次进入时自动检测未完成测评并恢复到断点位置继续作答
- (5) **测评报告生成与展示** — 汇总 10 题答题结果，计算最终 CEFR 等级（A1-C2）和四维度能力分（听力/口语/阅读/语法），生成可视化报告页面（等级标签 + 四维条形图 + 短板定位 + 学习建议），同时更新用户画像 `level_final` 和 `assessment_completed` 状态
- (6) **测评题库管理** — 运营人员后台对测评题目的增删改查，按维度（听力/口语/阅读/语法）和 CEFR 难度等级（A1-C2）分类管理，支持配置题目文本、选项、正确答案、难度标记；MVP 阶段每难度每维度 ≥ 5 题，总计 ≥ 120 题
