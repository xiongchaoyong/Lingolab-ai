# 模块 1：用户注册与多维度画像 — 详细规格说明

> P0 | 7 子功能 | 流程图 5 张 | 用例图：模块1-用例图.drawio

## (1) 用户注册

### 需求

- 用户名+密码注册，用户名 4-20 字符仅字母数字下划线全局唯一，密码 8-32 字符含字母+数字
- 同步采集年龄（自动归类）、学习目标（必选）、兴趣偏好（选填）
- 密码 bcrypt 加密存储，数据库不可逆；注册成功自动登录返回 JWT Token（24h）

### 输入

| 字段 | 类型 | 必填 | 规则 |
|------|------|:---:|------|
| username | string | ✅ | 4-20字符，字母数字下划线，全局唯一 |
| password | string | ✅ | 8-32字符，含字母+数字，bcrypt加密 |
| age | int | ✅ | 1-150 |
| learning_goal | enum | ✅ | 日常交流/考试/商务/出国/兴趣爱好 |
| interests | multi-enum | — | 音乐/体育/科技/美食/旅行/电影/文学/其他 |

### 处理

1. 校验字段格式 + 用户名唯一性 → 不通过返回 422/409
2. 密码 bcrypt 加密 → 写入 users 表
3. 年龄归类（6-12→儿童/13-17→青少年/18-22→大学生/23-50→职场/51+→中老年）
4. 自评等级映射（初级→A1/中级→B1/高级→B2）→ 写入 user_profiles
5. 生成 JWT Token → 返回前端，同步触发画像生成

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| user_id | 前端+DB | int | 用户ID |
| username | 前端 | string | 用户名 |
| token | 前端(Header) | string | JWT Token，24h有效 |
| age_group | user_profiles | string | 年龄归类标签 |

**接口：** `POST /api/auth/register`

## (2) 登录与 JWT 鉴权

### 需求

- 用户名+密码登录，验证通过返回 JWT Token（24h），所有后续请求 Header 携带 `Authorization: Bearer <token>`
- 后端中间件统一校验 Token 有效性+过期

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| username | string | ✅ | 登录账号 |
| password | string | ✅ | 明文密码（HTTPS传输） |

### 处理

1. 查询 users 表匹配 username → 不存在返回 401（与密码错误统一提示防枚举）
2. bcrypt 验证密码 → 不匹配返回 401
3. 生成 JWT Token（payload: user_id+role，expire: 24h）
4. 检查 assessment_completed → false 则前端强制跳转测评页

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| token | 前端 | string | JWT Token |
| expires_at | 前端 | datetime | 过期时间 |
| user_profile | 前端 | object | 用户画像摘要 |
| assessment_completed | 前端 | bool | 控制路由守卫 |

**接口：** `POST /api/auth/login`

---

## (3) 年龄自动归类

### 需求

- 注册时根据输入年龄自动映射年龄段标签，存入 `user_profiles.age_group`，用于内容风格适配

### 输入

| 字段 | 类型 | 必填 | 规则 |
|------|------|:---:|------|
| age | int | ✅ | 1-150 |

### 处理

1. 年龄校验：<1 或 >150 → 拒绝
2. 映射规则：6-12→儿童 / 13-17→青少年 / 18-22→大学生 / 23-50→职场 / 51+→中老年
3. 边界值（12/17/22/50）：偏简单策略——12→儿童、17→青少年、22→大学生、50→职场

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| age_group | DB+前端 | string | 儿童/青少年/大学生/职场/中老年 |

---

## (4) 用户自评等级

### 需求

- 注册时用户自评英语水平（初级/中级/高级），映射为临时 CEFR 等级，用于测评前初始内容推荐，测评完成后被 `level_test` 覆盖

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| level_self | enum | ✅ | 初级/中级/高级 |

### 处理

1. 映射：初级→A1 / 中级→B1 / 高级→B2
2. 写入 user_profiles.level_self + level_final（初始=level_self）
3. 测评完成后 → level_test 覆盖 level_final

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| level_self | DB | string | 初级/中级/高级 |
| level_final | DB | string | 初始=自评，测评后=实测 |

---

## (5) 用户画像生成

### 需求

- 整合注册信息+自评+年龄归类+兴趣标签，生成初始画像 JSON，测评完成后更新 level_final

### 处理

1. 聚合字段：username + age_group + learning_goal + interests + level_self + level_test(null) + level_final(同level_self) + assessment_completed(false)
2. 写入 user_profiles 表
3. 测评完成后：level_test=测评得分，level_final=测评等级，assessment_completed=true

### 输出

```json
{"user_id":1,"username":"zhangsan","age_group":"大学生","learning_goal":"日常交流",
 "interests":["音乐","旅行"],"level_self":"初级","level_test":null,
 "level_final":"A1","assessment_completed":false}
```

**接口：** `GET /api/user/profile` `PUT /api/user/profile`

---

## (6) 测评强制引导

### 需求

- 注册后首次登录/未完成测评用户 → 强制跳转测评页（模块2），锁定首页/发音/对话入口；测评完成后自动解锁

### 处理

1. 登录后检查 user_profiles.assessment_completed
2. false → 前端路由守卫拦截，强制跳转 `/assessment`
3. 测评完成后 → assessment_completed=true → 解除锁定
4. 用户直接 URL 访问锁定页 → 前端路由守卫拦截 → 重定向测评页

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| assessment_completed | 前端路由 | bool | false=锁定核心功能 |

**接口：** 登录接口 + `GET /api/assessment/status` 联合判断

---

## (7) 测评进度追踪

### 需求

- 检测用户是否有未完成测评，支持断点恢复；会话超 30min 自动过期

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| user_id | int | ✅ | JWT Token 解析 |

### 处理

1. 查询 assessment_sessions WHERE user_id AND status='in_progress'
2. 无会话 → 返回 has_pending=false → 开始新测评
3. 有会话 → 检查 updated_at：≤30min → 返回恢复信息 / >30min → 标记 expired → 重新开始

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| has_pending | 前端 | bool | 是否有未完成测评 |
| session_id | 前端 | UUID | 恢复用会话ID |
| answered_count | 前端 | int | 已答题数 |

**接口：** `GET /api/assessment/status`
