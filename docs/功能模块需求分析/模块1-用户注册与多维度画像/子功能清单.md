# 模块 1：用户注册与多维度画像 — 子功能清单

> 优先级：P0 | 参考 PRD：模块 1

- (1) 用户注册 — 用户名+密码注册，采集年龄/学习目标/兴趣偏好，服务端校验唯一性与合法性后创建账号，密码 bcrypt 加密存储
- (2) 登录与JWT鉴权 — 用户名密码登录，验证通过后颁发 JWT Token（24小时有效期），后续每次请求携带 Token 进行身份鉴权
- (3) 年龄自动归类 — 根据用户输入的年龄自动映射到 5 个年龄段（儿童/青少年/大学生/职场/中老年），影响默认内容策略
- (4) 用户自评等级 — 注册时用户自评英语水平（入门/基础/中级/中高级/高级/精通），作为测评前的临时等级用于初始内容推荐
- (5) 用户画像生成与管理 — 整合注册信息、自评等级、测评结果，生成多维度用户画像（年龄分组/学习目标/兴趣/等级），支持后续更新
- (6) 测评强制引导 — 注册后自动登录并强制跳转测评页（模块 2），测评完成前阻止访问首页及发音/对话等核心功能
- (7) 测评进度追踪 — 测评中途退出时保存当前答题进度，用户下次登录时恢复上次答题位置，已答题目不重复出现
