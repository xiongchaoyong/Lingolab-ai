# 模块 3：个性化学习路径规划 — 子功能清单

> 优先级：P1 | 参考 PRD：模块 3

- (1) **学习路径规则引擎** — 基于用户画像（年龄归类/学习目标/兴趣标签）和测评结果（四维能力分/CEFR 等级），执行短板优先 + 学习目标加权 + 年龄风格适配 + 兴趣偏好匹配的多因子规则计算，输出当日任务类型配比和内容筛选权重
- (2) **每日任务生成与推送** — 根据规则引擎输出的类型配比和筛选权重，从跟读内容库、对话场景库、听力训练库中匹配对应 CEFR 难度的内容，生成每日 3 个任务（跟读练习 5-10min + 情景对话 10-15min + 听力训练 5min），测评完成后立即生成首次任务，此后每日刷新
- (3) **用户任务干预操作** — 支持用户对当日任务进行四种干预：跳过任务（可选填原因）、换一个同类型同难度备选任务、手动反馈难度偏差（太简单/太难 → 下次推送难度 ±1）、完成 3 个任务后手动追加 1 个额外任务
- (4) **任务完成记录与历史回溯** — 记录每日每个任务的完成状态（pending/skipped/completed）、得分、实际耗时，存储到 `daily_tasks` 表，支持按日期回看历史任务记录；连续 3 天跳过同一类型时触发提示「是否不想练习此类任务？」
