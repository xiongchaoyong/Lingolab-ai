## (1) 学习路径规则引擎

### 需求

- 多因子规则计算：短板优先（最低维权重50%）+ 学习目标加权 + 年龄风格适配 + 兴趣标签加分
- 输出当日任务类型配比和内容筛选权重

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| user_id | int | ✅ | JWT解析 |
| user_profile | object | ✅ | age_group/learning_goal/interests/cefr_level |
| assessment_scores | object | — | {listening,speaking,reading,grammar}，新用户null |
| cefr_level | string | — | 新用户用level_self映射 |

### 处理

1. 读取用户画像 + 测评四维分数
2. 短板优先配比：取最低分维度 → 对应任务类型权重50%，其余三维均分50%
3. 学习目标加权：日常→场景+30% / 商务→场景+30%跟读+20% / 考试→跟读+30% / 出国→场景+30% / 兴趣→场景+20%跟读+20%
4. 年龄风格：儿童→趣味/青少年→校园/大学生→学术社交/职场→商务/中老年→日常旅行
5. 兴趣加分：content_tags ∩ user_interests → 每个命中+8

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| task_type_weights | 子功能(2) | object | {read_aloud, conversation, listening} |
| weakness_dimensions | 子功能(2) | array | 短板维度列表 |
| content_style_filter | 子功能(2) | string | 年龄风格标签 |
| interest_tags | 子功能(2) | array | 兴趣标签 |
| difficulty_adjustment | 子功能(2) | int | 用户手动难度偏移(-2~+2，初始0) |

**接口：** `POST /api/learning-path/calculate`（<100ms）

## (2) 每日任务生成与推送

### 需求

- 按规则引擎输出从内容库匹配CEFR难度内容，生成3任务：跟读(5-10min)+情景对话(10-15min)+听力(5min)
- 测评后立即生成首次任务，此后每日0点刷新，7天内不重复

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| user_id | int | ✅ | JWT解析 |
| task_type_weights | object | ✅ | 规则引擎输出 |
| cefr_level | string | ✅ | 用户CEFR等级 |
| content_style_filter | string | ✅ | 年龄风格 |
| interest_tags | array | — | 兴趣标签 |
| difficulty_adjustment | int | — | 难度偏移 |

### 处理

1. 检查当日是否已有任务 → 有且非手动刷新则直接返回
2. 有效CEFR = cefr_level + difficulty_adjustment（clamp A1-C2）
3. 任务1（跟读）：从跟读库筛选 CEFR+风格+兴趣+排除7天 → 推荐分降序取top1
4. 任务2（对话）：从对话库筛选 CEFR+目标场景优先+排除7天
5. 任务3（听力）：从听力库筛选 CEFR+风格+排除7天
6. 某类型无匹配 → 放宽±1级+去重窗口3天兜底 → 写入daily_tasks → 返回

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| tasks[] | 前端 | array | 3个任务，每个含task_id/type/content/duration/status/focus |
| task_date | 前端+DB | date | 任务日期 |
| total_duration | 前端 | string | 预估总时长"20-30min" |

**接口：** `GET /api/learning-path/today` `POST /api/learning-path/generate-tasks`

## (3) 用户任务干预操作

### 需求

- 四种干预：跳过（可选填原因）/ 换一个（同类型同难度备选，限3次）/ 调整难度（±1偏移，下次生效）/ 加量（3任务全完成+每日限1次）

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| action | enum | ✅ | skip/swap/adjust_difficulty/add_extra |
| task_id | int | 条件 | skip/swap时必填 |
| skip_reason | enum | — | too_hard/too_easy/not_interested/no_time/other |
| difficulty_feedback | enum | 条件 | too_easy/too_hard |

### 处理

1. **跳过：** 校验→检查同类型连续跳过天数→更新skipped→≥3天同类型→提示可关闭该类型
2. **换一个：** 校验+剩余次数→查同类型同难度备选(排除7天+当前)→取第二高分→替换content
3. **调整难度：** difficulty_preference ±= 1（clamp[-2,+2]）→ 下次规则引擎生效
4. **加量：** 校验3任务全完成+今日未追加→从短板维度匹配1个→写入第4任务

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| result | 前端 | string | skip_confirmed/swapped/added/difficulty_updated |
| new_task | 前端 | object | swap/add_extra时返回新任务 |
| warning_message | 前端 | string | 连续跳过/难度边界提示 |

**接口：** `POST /api/learning-path/tasks/{id}/skip` `POST /.../{id}/swap` `POST /.../preferences/difficulty` `POST /.../tasks/add-extra`

## (4) 任务完成记录与历史回溯

### 需求

- 每日任务状态(pending→completed/skipped/swapped)+得分+耗时持久化，支持按日期回溯(最近30天)+按类型筛选

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| user_id | int | ✅ | JWT解析 |
| date_from/date_to | date | — | 回溯范围，默认30天，最大365天 |
| task_type_filter | enum | — | all/read_aloud/conversation/listening |

### 处理

1. 查询 daily_tasks WHERE user_id + 日期范围 + 可选类型 → ORDER BY task_date DESC
2. 状态更新：task_id → pending→completed/skipped → UPDATE status,completed_at
3. 日历数据聚合：{YYYY-MM-DD: task_count}

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| records[] | 前端 | array | 任务记录列表（含日期/类型/内容快照/状态/得分/耗时） |
| calendar_data | 前端 | object | {YYYY-MM-DD: task_count} |

**接口：** `GET /api/learning-path/history` `PATCH /api/learning-path/tasks/{id}/status`
