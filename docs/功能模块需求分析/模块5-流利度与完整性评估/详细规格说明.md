# 模块 5：流利度与完整性评估 — 详细规格说明

> P1 | 4 子功能 | 流程图 1 张 | 用例图：模块5-用例图.drawio

---

## (1) 语音特征实时采集

### 需求

- 嵌入模块6每轮对话，从音频时长+Whisper转写+VAD静音段自动提取语速(WPM)/停顿频率(次/分钟)/重复率(%)三项指标，静默存储不打断对话。

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| audio_duration | float | ✅ | 前端录音秒数 |
| transcript | string | ✅ | Whisper转写文本 |
| word_timestamps | array | ✅ | [{word,start,end}] |
| vad_segments | array | — | [{start,end,is_speech}]，无VAD用0.5s阈值兜底 |

### 处理

1. WPM = total_words / (duration_seconds/60)，评分：120-170→满分25，每偏离10→-3
2. 停顿频率 = >0.5s静音段数 / (duration_seconds/60)，评分：<5次/min→20，每增1→-3
3. 重复率 = 重复词数/total_words×100，评分：<5%→20，每增2%→-4

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| wpm | 子功能(2) | float | 语速 |
| pause_rate | 子功能(2) | float | 停顿频率(次/min) |
| repetition_rate | 子功能(2) | float | 重复率(%) |
| fluency_features_json | DB | JSON | conversation_messages存储 |

---

## (2) 流利度多维度评分计算

### 需求

- 五维加权：语速25 + 停顿20 + 重复20 + 语法正确性(来自子功能3)20 + 内容相关性(来自子功能3)15 → 综合分0-100
- 分段评级：优秀≥85/良好70-84/中等55-69/初级40-54/入门<40

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| fluency_features | object | ✅ | 子功能(1)输出{wpm,pause_rate,repetition_rate} |
| grammar_score | int | ✅ | 子功能(3)输出0-20 |
| relevance_score | int | — | 子功能(3)输出0-15 |

### 处理

1. 五维分数映射（语速/停顿/重复按子功能1规则 → 语法/相关性直接从子功能3取值）
2. 维度缺失检测 → 缺失权重归零其余归一化
3. 加权求和 → 分段评级映射
4. 连续3轮下降检测 → 触发提示

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| total_score | 前端+DB | int | 0-100 |
| fluency_level | 前端 | string | 优秀/良好/中等/初级/入门 |
| dimension_scores | 前端 | object | {wpm,pause,repetition,grammar,relevance} |
| is_low_confidence | 前端 | bool | <3词时为true |

## (3) 语法正确性与语义相关性分析

### 需求

- Deepseek语法检查（错误数/总词数→0-20分）+ 场景语义匹配（high/medium/low/none→15/10/5/0分）。复用模块7能力仅需错误计数。

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| transcript | string | ✅ | 转写文本 |
| scene_context | string | ✅ | 模块6场景描述 |
| conversation_history | array | — | 近3轮上下文 |
| whisper_confidence | float | ✅ | 转写置信度 |

### 处理

1. 语法检查Prompt → Deepseek → 解析error_count → 映射：0→20/1→17/2→14/每+1→-3下限0
2. 语义相关性Prompt → Deepseek → 解析relevance(high/medium/low/none) → 映射15/10/5/0
3. 超时→标记N/A供子功能(2)降级处理

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| grammar_score | 子功能(2) | int | 0-20 |
| error_count | DB | int | 语法错误数 |
| relevance_score | 子功能(2) | int | 0-15 |
| relevance_level | 前端 | enum | high/medium/low/none |

---

## (4) 流利度汇总报告与历史追踪

### 需求

- 对话结束汇总各轮分数→综合分+分段评级+五维条形图+各轮趋势(标注最佳轮次)+改进建议
- 连续3轮下降→提示"要不要放慢节奏？"；历史写入fluency_history支持跨对话对比

### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| conversation_id | string | ✅ | 模块6会话ID |
| user_id | int | ✅ | JWT解析 |

### 处理

1. 查询conversation_messages所有轮fluency_scores → 过滤无效轮次
2. 综合分=各轮均值 → 分段评级 → 遍历检测连续下降 → 取最低维度生成改进建议
3. 写入fluency_history

### 输出

| 字段 | 去向 | 类型 | 说明 |
|------|------|------|------|
| average_score | 前端 | int | 综合流利度 |
| fluency_level | 前端 | string | 分段评级 |
| round_scores | 前端 | array | [{round_number,score,level}] |
| best_round | 前端 | int | 最佳轮次 |
| improvement_tip | 前端 | string | 改进建议 |
| decline_alert | 前端 | string | 连续下降提示 |

**接口：** `GET /api/fluency/report/{conversation_id}` `GET /api/fluency/history?days=30`
