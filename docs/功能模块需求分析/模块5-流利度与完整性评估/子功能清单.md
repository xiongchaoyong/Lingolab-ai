# 模块 5：流利度与完整性评估 — 子功能清单

> 优先级：P1 | 参考 PRD：模块 5

- (1) **语音特征实时采集** — 嵌入模块 6 每轮对话流程，从用户音频（时长 + VAD 静音段）和 Whisper 转写文本中自动提取三项基础指标：语速（每分钟有效词数）、停顿频率（长停顿 >0.5s 次数/分钟）、重复率（重复词数/总词数），静默执行不打断对话
- (2) **流利度多维度评分计算** — 五维加权计算综合流利度分数：语速 25 分 + 停顿频率 20 分 + 重复率 20 分 + 语法正确性 20 分 + 内容相关性 15 分，总分 0-100，映射分段评级（优秀 ≥85 / 良好 70-84 / 中等 55-69 / 初级 40-54 / 入门 <40）
- (3) **语法正确性与语义相关性分析** — 调用 Deepseek API 对转写文本进行语法错误检测（错误数/总词数 → 0-20 分）和场景上下文语义匹配度评估（与对话场景的语义相似度 → 0-15 分），复用模块 7 语法纠错能力
- (4) **流利度汇总报告与历史追踪** — 对话结束时汇总各轮流利度分数，生成可视化报告（综合分 + 分段评级 + 各轮趋势 + 最佳轮次 + 改进建议）；记录历史数据支持跨对话流利度对比和连续下降预警（连续 3 轮下降时提示「要不要放慢节奏？」）
