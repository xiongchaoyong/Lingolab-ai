# Lingolab 业务流程介绍文档

> 面向客户演示与产品介绍，按学习者、教师、运营三类角色介绍业务流程。

---

## 一、用户端 — 从测评定级到持续提升的完整学习流程

用户端是系统的核心，覆盖用户从零基础入门到持续提升的全过程。整体流程分为三个阶段：

```
┌────────── 入口阶段 ──────────┐    ┌────────── 循环阶段 ──────────────────┐
│                              │    │                                      │
│  注册画像 → 水平测评 → 路径规划 ──→ 每日学习 → 动态画像更新 → 任务调整 ──┘
│                              │    │   ↑                        │
│   (一次性，建立初始画像)        │    │   └────── 数据回流 ─────────┘
│                              │    │
└──────────────────────────────┘    │  观测层：进度追踪 + 效果预测 + 预警
                                    └──────────────────────────────────────┘
```

- **入口阶段**（一次性）：注册画像 → 水平测评 → 初始路径规划，建立用户初始画像和 CEFR 定级
- **循环阶段**（持续运行）：每日学习 → 训练数据写入画像 → EMA 重算各维度分数 → 识别新短板 → 调整后续任务 → 继续学习，形成"越学越精准"的正反馈闭环
- **观测层**（伴随运行）：进度可视化、效果预测、预警提醒，全程监控学习状态但不参与闭环回流

### 1.1 注册与画像构建

```
用户注册 → 填写个人信息（年龄、学习目标、偏好） → 构建多维画像
```

用户首次使用系统时，通过手机号或邮箱注册账号，填写年龄、学习目标（日常交流/考试备考/商务英语/出国旅行/兴趣爱好）等信息。系统据此构建用户多维画像，作为后续个性化服务的数据基础。

### 1.2 水平智能测评

```
进入测评 → 自适应答题（听力/口语/阅读/语法四维度） → CEFR 定级 → 能力雷达图
```

注册完成后，用户进入水平测评环节。系统采用自适应难度算法，根据用户答题情况动态调整题目难度，从听力、口语、阅读、语法四个维度全面评估英语水平。测评完成后输出 CEFR 等级（A1-C2）和各维度能力雷达图，精准定位用户的优势与短板。

### 1.3 个性化学习路径规划

```
测评结果 + 用户画像 → 知识图谱匹配 → 拓扑排序 → 每日学习任务推送
```

基于测评结果和用户画像，系统利用知识图谱（129个知识点节点 + 292条前置依赖边）和 NetworkX 拓扑排序算法，为每位用户生成最优学习路径。每日自动推送学习任务，包括单词学习、发音跟读、AI 对话、听力训练等。

### 1.4 每日学习训练

学习者在系统内完成四大核心训练：

**AI 智能对话练习**
```
选择场景 → 语音输入 → ASR 转写 → LLM 生成回复 → TTS 语音输出 → 继续对话
```

支持餐厅点餐、酒店入住、商务谈判、学术讨论、旅行出行等 8 大真实场景，端到端语音交互延迟 ≤ 2 秒。对话结束后，系统自动将发音评分和文本评分（语法正确率、词汇丰富度、对话参与度）摄入动态画像。

**发音评测与纠错**
```
选择内容 → 跟读录音 → wav2vec2 声学分析 → GOP 音素评分 → 五维评分报告 → 纠音练习
```

用户跟读标准发音后，系统从音素准确度、重音、连读、语调、节奏五个维度进行精细评分。评分结果自动写入用户技能分数表，触发画像重算。

**情景角色扮演**
```
选择角色（面试者/服务员/导游等） → 多轮互动对话 → 四维评分报告
```

用户选择角色后与 AI 进行多轮互动，系统从角色贴合度、语言恰当性、流利度、语法准确性四个维度进行评分。

**语法纠错与润色**
```
输入文本或语音 → LLM 分析 → 错误标注 + 纠正版本 + 地道表达推荐
```

支持语音和文字双模态输入，实时识别时态、主谓一致、冠词、介词搭配等语法错误，提供纠正版本和更地道的表达方式。

### 1.5 动态画像更新 — 核心闭环

```
训练完成 → 分数摄入 → EMA 重算各维度 → 更新用户等级 → 重新识别短板 → 调整后续任务
```

这是系统"越学越精准"的关键机制，每次训练后自动触发：

| 步骤 | 触发时机 | 具体动作 |
|------|----------|----------|
| ① 分数摄入 | 发音评测/对话练习/任务完成 | `profile_updater.ingest_*()` 将评分写入 `UserSkillScore` 表 |
| ② EMA 重算 | 每次分数摄入后自动调用 | 指数移动平均算法，新分数权重 30%，历史分数权重 70%，只计算最近 30 天 |
| ③ 等级更新 | EMA 重算完成后 | 根据综合分更新 `user_profiles.level_final`（A1-C2），用户画像等级随之变化 |
| ④ 短板识别 | 下次路径规划/推荐时 | 推荐服务读取最新各维度 EMA 分数，自动识别最低分维度作为当前短板 |
| ⑤ 任务调整 | 每日任务生成时 | 优先推荐短板相关任务，难度匹配当前等级，确保学习始终"对症下药" |

**举例说明**：用户初始测评等级为 B1，经过一周发音练习后，发音维度 EMA 分数从 55 提升到 68，但语法维度降至 50 成为新短板。系统自动将后续任务从"发音跟读"调整为"语法纠错 + 对话练习"，实现动态自适应。

### 1.6 学习进度可视化

```
学习数据汇聚 → 雷达图 + 趋势折线图 + 日历热力图 + 统计卡片
```

系统以可视化图表展示用户的多维度学习进步轨迹，用户可切换天/周/月/全部时间范围查看，清晰了解自己的成长路径。雷达图展示的维度分数直接来自动态画像的 EMA 计算值。

### 1.7 学习效果预测与预警

```
历史数据 → 线性回归预测 → 预计达标时间 → 偏差预警 → 反馈调整学习路径
```

系统基于用户历史学习数据进行线性回归分析，预测达到目标水平的时间和进度风险。当检测到连续未学习、学习时长下降超过 50%、发音得分停滞等异常情况时，自动触发预警提醒，并反馈调整学习路径。

### 1.8 激励与社交

**游戏化闯关**
```
每日闯关 → 配音挑战 → 获得积分 → 解锁勋章 → 排行榜竞争
```

**学习社区**
```
语音挑战广场 → 讨论区发帖 → 加入学习小组 → 组队学习 → 互评互助
```

### 1.9 智能客服

学习中遇到任何问题，可随时通过语音或文字向智能客服咨询，LLM 驱动 7×24 小时在线解答。

## 二、教师端 — 班级管理与作业点评的完整教学工具

教师端为教师提供班级管理、作业布置、学生评估的一站式工具。

### 2.1 班级管理

```
创建班级 → 生成邀请码 → 学生凭码加入 → 查看班级学生列表
```

教师创建班级后系统自动生成唯一邀请码，学生输入邀请码即可加入班级。教师可随时查看班级学生列表，了解每位学生的累计学习时长。

### 2.2 作业布置

```
选择班级 → 设置作业标题 → 选择作业类型 → 设定截止日期 → 发布作业
```

教师可向指定班级布置定制化口语作业，作业类型包括跟读练习、对话练习、角色扮演。学生端自动收到作业通知。

### 2.3 作业批阅与点评

```
查看学生提交 → 播放录音 → 在线评分 → 文字点评 → 学生收到反馈
```

教师查看学生提交的录音作业，系统自动给出 AI 初评分数作为参考，教师可调整评分并撰写文字点评。学生端实时收到教师的反馈。

### 2.4 学生能力报告

```
选择学生 → 能力雷达图 → 进步趋势 → 活动记录 → 薄弱点分析
```

教师可查看每位学生的详细能力报告，包括多维度能力雷达图、历史进步趋势、近期活动记录等，帮助教师精准发现学生的共性薄弱点，调整教学策略。

## 三、运营端 — 平台运营与数据监控的管理后台

运营端为平台运营人员提供用户管理、内容管理、数据分析和反馈处理的全套工具。

### 3.1 运营数据仪表盘

```
登录后台 → 运营看板 → 核心指标一览
```

运营看板展示平台核心运营指标：
- **DAU/MAU**：日活跃用户数 / 月活跃用户数
- **新增用户**：近 30 天注册趋势
- **留存率**：D1（次日留存）/ D7（七日留存）
- **内容统计**：各类学习资源数量分布
- **用户角色分布**：学习者 / 教师 / 管理员占比

### 3.2 用户管理

```
查看用户列表 → 搜索筛选 → 查看详情 → 禁用/启用账号 → 操作审计
```

运营人员可按用户名搜索、按角色筛选用户，查看用户详细信息和学习数据，对违规账号进行禁用或启用操作。

### 3.3 内容管理

```
选择内容类型 → 查看/新增/编辑/删除 → 素材库维护
```

运营人员管理平台全部学习内容，包括：
- **学习资源**：视频、音频、文章、练习题
- **配音素材**：影视片段、动画片段
- **挑战题库**：每日闯关题目、语音挑战题目

### 3.4 反馈管理

```
查看用户反馈 → 筛选状态 → 查看详情 → 回复处理 → 标记已处理
```

集中管理用户提交的反馈和投诉，支持按状态筛选（待处理/已回复/已关闭），运营人员可直接回复用户并标记处理状态。

### 3.5 操作日志审计

所有管理员操作自动记录到操作日志，包括操作人、操作类型、操作对象、操作时间，确保平台运营安全可追溯。

```
│  │              │    │              │    │              │    │
│  │ 注册测评      │    │ 班级管理      │    │ 用户管理      │    │
│  │ 路径规划 ◄──┐│    │ 作业布置      │    │ 内容管理      │    │
│  │ 每日训练 ──┐││    │ 提交点评      │    │ 数据仪表盘    │    │

│  │ 社区互动    ││    │              │    │              │    │
│  └──────────────┘    └──────────────┘    └──────────────┘    │
│         │                   │                   │              │
│         └───────────────────┼───────────────────┘              │
│                             │                                  │
│                 核心 AI 能力层                                   │
│  ASR（WhisperX）→ LLM（千问 qwen-plus）→ TTS（Edge TTS）       │

协作流程：
  学习者每日训练 → 动态画像自动更新 → 路径规划自适应调整 → 持续精准提升
  教师查看学生画像和报告 → 发现薄弱点 → 布置针对性作业 → 学生完成 → 数据回流
  运营管理内容和用户 → 保障平台运转 → 学习者获得优质体验
  智能客服 7×24h 三端全覆盖
```

## 五、核心亮点总结

| 亮点 | 说明 |
|------|------|
| **动态画像闭环** | 每次训练后自动更新用户画像（EMA 算法），识别新短板，调整后续任务，实现"越学越精准" |
| **端到端语音交互** | ASR → LLM → TTS 全链路延迟 ≤ 2 秒，接近真人对话体验 |
| **专业级发音评测** | 五维音素级评分，远超市面"跟读打分"方案 |
| **动态画像系统** | EMA 指数移动平均算法，每次训练后自动重算用户等级和短板，驱动后续任务自适应调整 |
| **全年龄段覆盖** | 儿童到中老年，日常交流到商务谈判，一套系统全覆盖 |
| **三端协同** | C 端学习 + B 端教学管理 + 运营后台，完整商业闭环 |
| **成本可控** | LLM 使用国产千问，TTS 使用微软免费方案，ASR 和评测本地运行 |
