## 一、架构理念

### 管线化设计（Pipeline Architecture）

每个模型承担单一职责，模型间通过文本中转，环节可独立替换、可观测、可调试。

```
用户语音
    │
    ▼
┌──────────┐    转写文本    ┌──────────────────┐
│ WhisperX │──────────────▶│  deepseek-v4-flash │
│  (ASR)     │               │  (对话/纠错/推荐)   │
└──────────┘                └────────┬─────────┘
     │                               │
     │ 转写文本                      │ AI 回复文本
     ▼                               ▼
┌──────────┐                ┌──────────┐
│  wav2vec2   │                │ Edge TTS  │
│ (发音评分) │                │ (语音合成) │
└──────────┘                └─────┬────┘
     │                            │
     ▼                            ▼
  评分结果                     语音回复播放

┌──────────┐
│  Milvus   │ ← 长期记忆 / 推荐检索（P2上线）
└──────────┘
```

### WhisperX 在项目中的功能

| 功能 | 说明 |
|------|------|
| **发音评测** | 锁定具体哪个单词读错了，高亮显示 |
| **流利度评估** | 计算单词间隔时间，判断是否卡顿 |
| **逐词跟读** | 播放音频时同步高亮当前单词 |
| **语法纠错** | 把每个词的时间戳给 deepseek，做精确纠错 |



















### 为什么不用端到端语音模型

端到端模型（如 Fun-Audio-Chat-8B）是黑盒，存在三个致命问题：

| 问题 | 说明 |
|------|------|
| **评测无据** | 无法从黑盒获取转写文本，语法纠错、流利度评估、对话评分均无数据源 |
| **质量不足** | 8B 参数不足以支撑多轮角色扮演和复杂上下文 |
| **不可替换** | 黑盒模型绑死所有环节，ASR/LLM/TTS 任一环节想升级都做不到 |

## 三、各模型职责详解

### 1. WhisperX — 速记员

| 维度 | 说明 |
|------|------|
| **定位** | 唯一 ASR 入口，所有语音输入统一经 WhisperX 转写为文字 |
| **调用场景** | 模块 2（测评口语题）、模块 4（发音跟读）、模块 6（AI 对话）、模块 8（角色扮演）、模块 16（语音提问） |
| **输出** | 带时间戳的转写文本，供后续所有文本处理链路消费 |
| **部署** | GPU 服务器自部署，数据不出域 |
| **性能要求** | 单次转写 < 1s |

### 2. deepseek-v4-flash — 语文老师

| 维度 | 说明 |
|------|------|
| **定位** | 核心 LLM，承担所有文本生成和语义理解任务 |
| **调用场景** | |
| | — 模块 2：口语题自由表达评分（内容/语法/词汇/连贯性） |
| | — 模块 3：学习路径任务生成 |
| | — 模块 6：对话回复生成 + 难度控制 |
| | — 模块 7：语法纠错 + 地道表达润色 |
| | — 模块 8：角色扮演 Prompt 驱动 |
| | — 模块 9：推荐内容匹配 |
| | — 模块 16：智能客服问答 |
| **性能要求** | 对话回复 < 1.5s，纠错/评分 < 1s |
| **成本** | 1 元/百万 token，单次对话约消耗 3000-5000 token |

### 3. wav2vec2 — 发音教练

| 维度 | 说明 |
|------|------|
| **定位** | 基于自监督学习的语音表示模型，提取音素级特征用于发音评分 |
| **厂商** | Meta AI |
| **许可证** | Apache 2.0 |
| **技术链路** | WhisperX（ASR + 时间对齐）→ wav2vec2（特征提取 + 强制对齐）→ phonemizer（音素对比评分） |
| **评分维度** | 准确度（音素编辑距离）、流利度（时间对齐偏差）、完整度（内容匹配率） |
| **评分粒度** | 单词级 + 音素级，音素按得分绿/黄/红着色定位 |
| **模型大小** | 基础版 ~300MB，大版 ~1GB |
| **硬件** | CPU 可跑，推荐 GPU 加速 |
| **部署** | HuggingFace transformers / fairseq 本地加载，FastAPI 封装为评分服务 |
| **数据安全** | 音频不出服务器，无需上传第三方 |

### 4. Edge TTS — 播音员

| 维度 | 说明 |
|------|------|
| **定位** | 所有语音输出的统一 TTS 引擎，完全免费 |
| **厂商** | 微软 |
| **技术** | 神经网络 TTS，Azure Speech 同款引擎 |
| **调用方式** | `edge-tts` Python 库，无需注册、无需 API Key |
| **调用场景** | 模块 4（标准音播放）、模块 6（AI 对话语音回复）、模块 8（角色扮演语音回复） |
| **音色** | 50+ 英语音色（美式/英式/澳式等），推荐 Jenny(美式女声)、Sonia(英式女声) |
| **SSML 控制** | 支持语速(0.5~2x)、停顿、重音、情感风格 |
| **时间戳** | 句级边界时间戳（SentenceBoundary），单词级需配合 WhisperX 对齐 |
| **优势** | 免费、音质好、免部署、网络依赖小 |
| **数据安全** | 文本发至微软服务器合成，与豆包 TTS 同级别风险 |

### 5. Milvus — 学习委员的笔记本

| 维度 | 说明 |
|------|------|
| **定位** | 向量数据库，长期记忆 + 语义检索 |
| **上线时间** | P2（P0/P1 阶段用 MySQL JSON 兜底） |
| **调用场景** | |
| | — 用户历史发音错误语义检索（相似错误案例推荐） |
| | — 学习资料语义匹配（相似内容推荐） |
| | — 长期学习记忆（跨 session 上下文） |
| **部署** | 开源自部署，Docker Compose |

## 六、技术风险与应对

| 风险 | 应对 |
|------|------|
| wav2vec2 本地推理延迟高 | 评估异步返回；GPU 加速；可降级为简版评分 |
| deepseek-v4-flash 不稳定 | 超时降级预设回复；前端骨架屏 + 自动重试 |
| Edge TTS 合成失败 | 降级为 macOS say / 仅展示文字回复 |
| 端到端延迟 > 5s | 流式 TTS 首块音频先播；WhisperX 和 deepseek-v4-flash 并行执行 |
| 多年龄发音泛化差 | 初期聚焦 15-40 岁；儿童/老人用宽松阈值 |
| 自部署模型运维 | WhisperX + wav2vec2 + Milvus 全部本地化部署，统一服务管理 |

## 八、实测验证

> 以下为在 Apple M4 / macOS 环境下各模型的实测结果（2026-06-04）

| 模型 | 功能 | 实测耗时 | 设备 | 状态 |
|------|------|:---:|------|:---:|
| **WhisperX** | 语音转文字（small） | 1.3s | CPU int8 | ✅ 通过 |
| **WhisperX** | 单词级时间对齐 | 0.1s | CPU int8 | ✅ 通过 |
| **wav2vec2** | CTC 强制对齐 | 即时 | MPS GPU | ✅ 通过 |
| **wav2vec2** | GOP 发音评分 | 即时 | MPS GPU | ✅ 通过 |
| **Edge TTS** | 基础合成（4音色） | < 1s | 网络调用 | ✅ 通过 |
| **Edge TTS** | SSML 语速控制 | < 1s | 网络调用 | ✅ 通过 |
| **Edge TTS** | 句级时间戳 | < 1s | 网络调用 | ✅ 通过 |

### 关键发现

1. **WhisperX** 在 Apple Silicon 上必须用 `device=cpu` + `compute_type=int8`（faster-whisper/ctranslate2 不支持 MPS），M4 CPU 速度依然足够
2. **wav2vec2** 发音评测模型支持 MPS GPU 加速，94M 参数，内存占用 ~360MB
3. **Edge TTS** 完全免费，无需注册，SSML 可精确控制语速(0.5~2x)和停顿
4. Edge TTS 仅提供句级时间戳，**单词级时间戳**需组合 WhisperX 对齐实现
5. 国内网络需设置 `HF_ENDPOINT=https://hf-mirror.com` 下载 HuggingFace 模型
6. NLTK 数据（punkt_tab、cmudict、averaged_perceptron_tagger_eng）需通过 ghproxy 镜像下载

