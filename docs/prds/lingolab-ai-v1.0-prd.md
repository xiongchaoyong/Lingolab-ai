## 一、整体需求分析

### 1.1 项目定位

面向全年龄段用户，以 **AI 驱动的英语口语评测 + 情景对话为核心**，提供全天候个性化口语训练服务。

### 1.2 用户角色

| 角色 | 典型场景 | 涉及模块 |
|------|---------|:---:|
| **学习者(普通用户)** | 注册→测评→跟读→对话→看进度 | 1-13 |
| **教师** | 看班级报告→布置作业→点评学生→组织比赛 | 14 |
| **运营人员** | 管用户→审内容→配活动→看数据→处理投诉 | 15 |
| **系统智能客服** | 自动答疑、问题转人工 | 16 |

### 1.6 技术栈

| 层次 | 选型 | 理由 |
|------|------|------|
| 前端 | Vue 3 + Vite | SPA，组件化，生态完善 |
| 后端 | Python FastAPI | AI 生态原生支持，开发效率高 |
| 数据库 | MySQL 8.0 | 成熟稳定，团队熟悉 |
| ORM | SQLAlchemy 2.0 async | 异步数据库操作 |

| 语音转写(ASR) | WhisperX（开源） | 基于 Whisper 的增强版，带单词级时间对齐，为语法纠错/流利度评估提供文字稿 |
| 对话生成(LLM) | deepseek-v4-flash（深度求索） | 对话生成 + 语法纠错 + 语义评分 + 内容推荐 + 智能客服 |
| 发音评测 | wav2vec2（Meta） | Apache 2.0 开源，HuggingFace 本地加载，音素级特征提取 + 强制对齐，零费用 |
| 语音合成(TTS) | 豆包 TTS（字节跳动） | 多音色、有情感，替换原 Edge TTS 单一音色 |

### 1.7 模型清单

| 序号 | 模型/服务 | 厂商 | 承担功能 | 一句话职责 |
|:---:|------|------|------|------|
| 1 | **WhisperX** | 开源社区 | 功能 2/4/6/8：语音转文字 + 单词级对齐 | 速记员——把用户说的话一字不差写成文字，精确标注每个词的时间戳 |
| 2 | **deepseek-v4-flash** | 深度求索 | 功能 2(评分)/3(路径)/6(对话)/7(纠错)/8(角色)/9(推荐)/16(客服) | 语文老师——批改文字稿、生成对话回复、推荐学习内容 |
| 3 | **wav2vec2** | Meta | 功能 4(发音)/5(流利度辅助) | 发音教练——自监督语音特征提取，音素级强制对齐，零费用 |
| 4 | **豆包 TTS** | 字节跳动 | 功能 4(标准音)/6(语音回复)/8(语音回复) | 播音员——把 AI 回复用自然、有感情的声音读出来 |
| 5 | **Milvus** | Zilliz | 功能 9(推荐)/长期记忆（P2 上线） | 学习委员的笔记本——记住每个学生的错题和进步，语义检索相似内容 |

**架构关系**：管线化设计，各模型独立可替换，每个环节输出可观测：

```
用户语音 → WhisperX(ASR) → 转写文本 ┬→ wav2vec2(发音评分)
                                       └→ deepseek-v4-flash(对话/纠错/推荐)
                                              │
                                        豆包TTS(语音合成)
                                              │
                                         语音回复播放

长期记忆/推荐检索 → Milvus(P2) / MySQL JSON(P0/P1)
```

> **为什么不选端到端语音模型（如 Fun-Audio-Chat-8B）**：
> 端到端黑盒无法获取中间转写文本，导致语法纠错、流利度评估、对话评分无数据源；
> 8B 参数对话质量不足以支撑角色扮演和多轮上下文；
> 管线化架构每个环节可独立替换、可观测、可调试。

### 1.8 成本分析

| 模型 | 费用类型 | MVP 月成本估算（DAU 100） | 说明 |
|------|:---:|:---:|------|
| WhisperX | 🟢 免费 | 0 元 | 开源自部署，GPU 服务器已覆盖 |
| deepseek-v4-flash | 🟡 按量 | ~15 元/月 | 1元/百万token，单次对话 ~0.5分钱 |
| wav2vec2 | 🟢 免费 | 0 元 | Meta 开源（Apache 2.0），HuggingFace 本地加载 |
| 豆包 TTS | 🟢 免费 | 0 元 | 火山引擎月免费 100 万字符，MVP 够用 |
| Milvus | 🟢 免费 | 0 元 | 开源自部署 |

> **MVP 阶段总模型成本：约 15 元/月**（仅 deepseek-v4-flash API 费用），随用户量线性增长但单价极低。

### 1.9 wav2vec2 技术说明

| 维度 | 说明 |
|------|------|
| **厂商** | Meta AI |
| **许可证** | Apache 2.0 |
| **核心技术栈** | WhisperX（ASR + 对齐）→ wav2vec2（特征提取 + 强制对齐）→ phonemizer（音素对比评分） |
| **评分维度** | 准确度（音素编辑距离）、流利度（时间对齐偏差）、完整度（内容匹配率） |
| **评分粒度** | 单词级 + 音素级 |
| **部署方式** | HuggingFace transformers / fairseq 本地加载，FastAPI 封装评分服务 |
| **硬件需求** | CPU 可跑，GPU 加速推理更快 |
| **数据安全** | 音频不出服务器，无需上传第三方 |

> **发音评测链路**：用户录音 → WhisperX 转写+对齐 → wav2vec2 提取音素特征 → phonemizer 对比标准音素 → 评分结果。音素准确度由 wav2vec2 音素级特征直接对比得出，流利度和完整度由时间对齐偏差和内容匹配率计算。

## 二、模块详细需求

### 模块 1：用户注册与多维度画像 `P0`

#### 需求描述

用户通过本地账号密码注册，采集年龄、学习目标、兴趣偏好，系统自动生成用户画像。注册后必须完成水平测评（模块 2）才能进入主功能。

#### 注册方式

- **本地账号密码登录**，不接入第三方登录（微信/Google/OAuth）
- 用户名 + 密码注册，用户名全局唯一
- JWT Token 鉴权，24 小时有效期

#### 注册流程

```
注册页 → 填写信息 → 提交 → 自动登录 → 强制跳转测评页（模块2）
                                              │
                                       测评完成后进入首页
```

#### 采集字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| username | string | ✅ | 4-20 字符，字母数字下划线，全局唯一 |
| password | string | ✅ | 8-32 字符，含字母+数字，bcrypt 加密存储 |
| age | int | ✅ | 输入实际年龄，系统自动归类 |
| learning_goal | enum | ✅ | 日常交流 / 考试 / 商务 / 出国 / 兴趣爱好 |
| interests | multi-enum | — | 可选填：音乐/体育/科技/美食/旅行/电影/文学/其他 |

#### 年龄自动归类规则

| 年龄区间 | 归类标签 | 默认内容策略 |
|:---:|------|------|
| 6-12 | 儿童 | 趣味场景、游戏化优先、简单词汇 |
| 13-17 | 青少年 | 校园场景、考试导向可选、中等难度 |
| 18-22 | 大学生 | 学术+社交场景、四六级/雅思托福可选项 |
| 23-50 | 职场 | 商务场景、邮件电话、专业词汇 |
| 51+ | 中老年 | 旅行+日常场景、慢语速、大字界面 |

#### 水平定级逻辑

```
注册自评 level_self → 初始内容推荐（临时等级）
         │
         ▼
    必须完成模块2测评
         │
         ▼
  测评结果 level_test ←── 覆盖自评
         │
         ▼
  综合等级 = level_test（以测评为准）
```

自评仅用于测评前的初始内容难度，最终定级以测评结果为准。

#### 画像数据结构

```json
{
  "user_id": 1,
  "username": "zhangsan",
  "age_group": "大学生",
  "learning_goal": "日常交流",
  "interests": ["音乐", "旅行"],
  "level_self": "初级",
  "level_test": null,
  "level_final": null,
  "assessment_completed": false
}
```

#### 边界情况

| 场景 | 处理 |
|------|------|
| 用户名已存在 | 返回 `409`，提示「用户名已被注册」 |
| 密码不符合规则 | 返回 `422`，提示「密码需 8-32 位，包含字母和数字」 |
| 注册后未完成测评直接关闭 | 下次登录强制跳转测评页 |
| 测评中途退出 | 保存进度，重新进入时恢复上次答题位置 |
| 年龄输入异常值（<1 或 >150） | 拒绝提交，提示「请输入有效年龄」 |

#### 验收标准

- [ ] 用户名+密码可完成注册并自动登录
- [ ] 重复用户名注册返回 409 错误
- [ ] 密码 bcrypt 加密存储，数据库中不可逆
- [ ] 年龄自动归类正确（覆盖 5 个区间边界值）
- [ ] 注册后首次登录强制跳转到测评页
- [ ] 测评完成后 `assessment_completed` 变为 `true`
- [ ] 测评完成前无法访问首页/发音/对话功能







### 模块 2：英语水平智能测评 `P0`

#### 需求描述

注册后强制完成一次自适应测评，覆盖听力、口语、阅读、语法四维度，动态调整难度，精准定级 CEFR（A1-C2），定位各维度能力短板。

#### 题量与时长

- **共 10 题**，预计完成时间 8-12 分钟
- 分布：听力 3 题 + 口语 2 题 + 阅读 3 题 + 语法 2 题
- 题序交错排列（非按维度分块），减少用户疲劳

#### 自适应规则

```
初始难度 = 用户自评等级对应的 CEFR 起点

每题作答后：
  答对 → 下一题难度 +0.5 级（如 B1 → B1+）
  答错 → 下一题难度 -0.5 级

最终等级 = 10 题稳定后的难度区间
各维度能力分 = 该维度题目的正确率 × CEFR 映射
```

**CEFR 等级映射**：

| 分数区间 | CEFR 等级 | 标签 |
|------|:---:|------|
| 0-20 | A1 | 入门 |
| 21-40 | A2 | 基础 |
| 41-60 | B1 | 中级 |
| 61-80 | B2 | 中高级 |
| 81-95 | C1 | 高级 |
| 96-100 | C2 | 精通 |

#### 四维度测试方式

| 维度 | 题数 | 题型 | 评测方式 |
|------|:---:|------|------|
| 听力 | 3 | 听短对话/独白，选择正确答案 | 客观题，系统自动判分 |
| 口语 | 3 | 给定话题，用户自由表达录音 | WhisperX 转写 + deepseek-v4-flash 评分 |
| 阅读 | 3 | 完形填空/阅读理解 | 客观题，系统自动判分 |
| 语法 | 2 | 选择题（时态/语态/句型） | 客观题，系统自动判分 |

#### 口语题详细流程

```
1. 展示话题（如 "Describe your favorite food"）
2. 用户准备 15 秒
3. 录音 30-60 秒
4. WhisperX 转写为文本
5. deepseek-v4-flash 对转写文本评分：
   - 内容相关性（0-25）
   - 语法正确性（0-25）
   - 词汇丰富度（0-25）
   - 逻辑连贯性（0-25）
   → 总分 0-100
```

#### 题库管理

- **人工预录入**，保证质量可控、评分标准稳定
- 题目按 CEFR 难度标记（A1/A2/B1/B2/C1/C2）
- 每条题目包含：题目文本、选项（客观题）、正确答案、所属维度、难度等级
- MVP 阶段每难度每维度准备 ≥ 5 题（总计 ≥ 120 题）

#### 测评报告

测评完成后生成报告，包含：

```
┌─────────────────────────┐
│  测评报告               │
│  CEFR 等级：B1（中级）   │
│                         │
│  听力  ████████░░ 78    │
│  口语  ██████░░░░ 55 ← 短板 │
│  阅读  ████████░░ 82    │
│  语法  ███████░░░ 68    │
│                         │
│  建议：重点提升口语表达  │
└─────────────────────────┘
```

#### 边界情况

| 场景 | 处理 |
|------|------|
| 口语未检测到语音 | 标记 0 分，提示「未检测到语音」，不计入自适应难度调整 |
| 口语录音 < 5 秒 | 提示「录音过短，请重新作答」，允许重录 1 次 |
| 测评中断（关闭/网络） | 已答题目保存，下次继续；已答题不重复出现 |
| 10 题全部答对/全错 | 命中特殊规则：全对 → 追加 1 题 C2 难度确认；全错 → 追加 1 题 A1 难度兜底 |
| WhisperX 转写失败 | 返回 500，提示用户重新录音 |

#### 验收标准

- [ ] 10 题完成时间在 8-12 分钟内
- [ ] 自适应难度调整生效（答对升、答错降）
- [ ] 口语话题自由表达可正常录音并转写
- [ ] 测评报告正确展示 CEFR 等级和四维分数
- [ ] 中途退出后可恢复进度
- [ ] 测评完成后 user_profiles.level_final 正确更新
- [ ] 测评完成前无法访问首页、发音练习、对话功能



### 模块 4：AI 发音评测与纠错 `P0`

#### 需求描述

用户跟读标准发音，系统从音素准确度、重音、连读、语调、节奏五个维度精细评分，定位发音问题并给出文字纠音建议。支持单词级和句子级两种跟读模式。

#### 跟读模式

| 模式 | 内容 | 适合用户 | 评测重点 |
|------|------|------|------|
| 单词模式 | 单个单词，含音标 | A1-A2 初学者 | 音素准确度 + 重音 |
| 句子模式 | 完整句子（5-15 词） | B1+ 中高级 | 全部五维 + 连读 + 语调 |

用户可自由切换模式，系统根据 CEFR 等级默认推荐。

#### 五维评分体系

| 维度 | 权重 | 评估方式 | 输出 |
|------|:---:|------|------|
| 音素准确度 | 40% | wav2vec2 音素级评测（WhisperX + wav2vec2 强制对齐） | 0-100 分 + 错误音素定位 |
| 重音位置 | 15% | wav2vec2 重音检测 | 0-100 分 + 重音偏移标注 |
| 连读表现 | 15% | wav2vec2 连读检测（仅句子模式） | 0-100 分 + 漏连位置 |
| 语调曲线 | 15% | wav2vec2 语调评测 | 0-100 分 + 语调偏差标注 |
| 节奏感 | 15% | wav2vec2 节奏评测 | 0-100 分 + 节奏偏差 |

**综合分数** = 加权平均，各维度权重按模式调整。
- 单词模式：准确度 60% / 流利度 20% / 完整度 20%
- 句子模式：准确度 50% / 流利度 25% / 完整度 25%

> wav2vec2 输出三维评分（准确度/流利度/完整度），重音/语调/节奏特征由 wav2vec2 隐式提取，在准确度和流利度中体现。

#### 评测流程

```
1. 选择模式（单词/句子）
2. 展示跟读内容（文字+标准音播放，豆包 TTS 合成）
3. 用户点击录音，跟读
4. 上传音频 → wav2vec2 发音评测（本地模型推理服务）
5. 五维评分计算
6. 返回评分结果 + 纠错建议（纠错建议由 deepseek-v4-flash 生成）
```

**单次评测延迟目标**：< 3 秒（上传→评分结果返回）

#### 评分反馈内容

| 反馈项 | 说明 |
|------|------|
| 综合分数 | 0-100 分，颜色标注（绿 ≥80 / 黄 60-79 / 红 <60） |
| 五维分项分数 | 雷达图 + 每个维度的分数和简短评价 |
| 错误音素定位 | 标注单词中哪些音素发音有误（如 `th /θ/ → /s/`） |
| 纠音文字建议 | 针对每个错误音素，给出中文纠音方法（如「舌尖轻触上齿，气流从齿缝挤出」） |
| 标准音标 | 展示单词的 IPA 音标作为参考 |

#### 内容库

| 难度 | 单词模式 | 句子模式 |
|------|------|------|
| A1 | 100 个高频基础词 | 50 句（3-5 词/句） |
| A2 | 100 个日常词汇 | 50 句（5-8 词/句） |
| B1 | 80 个中阶词汇 | 50 句（8-12 词/句） |
| B2+ | 60 个高阶词汇 | 40 句（10-15 词/句） |

内容预录入，含标准音频 + IPA 音标 + 音素标注。

#### 边界情况

| 场景 | 处理 |
|------|------|
| 录音无声 | 提示「未检测到语音，请重试」，不计分 |
| 录音 < 1 秒 | 提示「录音过短」，允许重录 1 次 |
| 背景噪音过大 | wav2vec2 返回低置信度 → 提示「环境噪音较大，建议在安静环境练习」 |
| 转写内容与原文完全不匹配 | 标记为「可能读错内容」，展示 WhisperX 转写结果，提示用户核对 |
| 评测 API 超时 | 返回 504，提示「评分服务繁忙，请稍后重试」 |
| 跟读内容含生僻词 | 提供音标 + 标准音播放按钮（豆包 TTS），支持先听后读 |

#### 验收标准

- [ ] 单词模式可选择并完成跟读评分
- [ ] 句子模式可选择并完成跟读评分
- [ ] 五维分数返回完整，综合分加权正确
- [ ] 错误音素定位准确（人工抽查 20 条）
- [ ] 纠音建议文字可读、有实际指导意义
- [ ] 单次评测 < 3 秒（含 wav2vec2 本地推理）
- [ ] 录音无声/过短/噪音大等异常场景有对应提示

### 模块 6：智能语音对话练习 `P0`

#### 需求描述

基于 deepseek-v4-flash 大语言模型驱动 AI 虚拟对话伙伴，支持多场景沉浸式语音对话。用户语音输入 → WhisperX 转写 → deepseek-v4-flash 生成回复 → 豆包 TTS 语音输出，形成完整语音对话闭环。

#### MVP 场景

| 序号 | 场景 | 难度范围 | 典型对话内容 |
|:---:|------|:---:|------|
| 1 | 自我介绍 | A1-B1 | 姓名/职业/兴趣/家庭介绍、初次见面寒暄 |
| 2 | 问路指路 | A2-B2 | 地铁/公交/地址描述、方向指引 |
| 3 | 购物 | A2-B2 | 商品询价/尺码/颜色/付款/退货 |
| 4 | 餐厅 | A1-B2 | 预定/点餐/忌口/结账/投诉 |

后续迭代扩充至 60+ 场景（酒店、面试、看病、旅行、学术讨论等）。

#### 对话流程

```
1. 选择场景 → AI 开场白（文字+语音，豆包 TTS）
2. 用户语音回复 → 录音
3. WhisperX 转写为文本
4. deepseek-v4-flash 生成回复（含难度控制）
5. 豆包 TTS 合成语音回复
6. 展示回复文字 + 播放语音（双模态）
7. 重复 2-6，共 5-8 轮
8. 对话结束，生成本次表现评分
```

#### 端到端延迟

| 阶段 | 延迟目标 |
|------|:---:|
| 录音上传 | < 0.5s |
| WhisperX 转写 | < 1s |
| deepseek-v4-flash 生成回复 | < 1.5s |
| 豆包 TTS 合成 | < 1s |
| **全链路总目标** | **< 5s**（MVP）/ < 3s（优化后） |

#### 难度自适应

| CEFR 等级 | 词汇难度 | 语速 | 回复长度 | 语法纠错介入 |
|------|:---:|:---:|:---:|:---:|
| A1-A2 | 基础 500-1000 词 | 慢（120 wpm） | 1-2 句 | 每轮轻提示 |
| B1 | 中阶 1500-2500 词 | 正常（150 wpm） | 2-3 句 | 每 3 轮提示 1 次 |
| B2+ | 高阶 3000+ 词 | 正常偏快（170 wpm） | 3-5 句 | 仅在明显错误时提示 |

AI 根据用户连续 3 轮错误率自动降低/提高难度，无需手动切换。

#### 对话记忆

- 保留最近 **10 轮**对话上下文（包括已纠正的语法错误）
- 同一场景内保持角色和故事连贯性
- 切换场景时清除上下文

#### 对话结束评分

| 维度 | 说明 | 权重 |
|------|------|:---:|
| 发音准确率 | 各轮发音分的均值 | 30% |
| 语法正确率 | 转写文本中语法错误占比 | 30% |
| 词汇丰富度 | 使用词汇的多样性 | 20% |
| 对话参与度 | 回复长度 + 主动提问次数 | 20% |

#### 回复输出方式

- **文字**：聊天气泡形式展示，含纠错标注
- **语音**：豆包 TTS 合成，自动播放
- 语音播放后文字保留在聊天记录中，可回看

#### 边界情况

| 场景 | 处理 |
|------|------|
| 用户沉默 ≥ 5 秒 | AI 主动提示 "I didn't catch that, could you repeat?" |
| WhisperX 转写置信度低 | 展示转写结果 + 标注「识别可能不准」，让用户确认后再生成回复 |
| deepseek-v4-flash API 超时 | 退回预设应急回复，提示「AI 正在思考，请稍等」 |
| 豆包 TTS 合成失败 | 仅展示文字回复，标注「语音播放暂时不可用」 |
| 用户说中文 | 转写后，AI 回复「Sorry, could you say that in English?」鼓励用英语 |
| 对话中途退出 | 保存进度，下次可继续该场景或重新开始 |
| 用户回复内容与场景无关 | AI 温和引导回场景主题，如 "Let's focus on ordering. What would you like to eat?" |

#### 验收标准

- [ ] 4 个 MVP 场景均可发起完整对话

- [ ] 对话结束评分返回 4 维分数
- [ ] 用户沉默 5 秒后 AI 主动提示
- [ ] 对话中途退出后进度可恢复

### 模块 5：流利度与完整性评估 `P1`

#### 需求描述

嵌入模块 6 对话中，每轮对话自动评估用户表达的流利度和内容完整性。不额外占用用户时间，静默评分，对话结束时汇总。

#### 评估方式

- **触发时机**：模块 6 每轮对话中，用户语音转写后自动评估
- **用户感知**：对话过程中不打断，对话结束统一展示
- **数据来源**：WhisperX 转写文本 + 音频时间戳 + deepseek-v4-flash 语义分析

#### 五维评估指标

| 指标 | 计算方式 | 满分 | 数据来源 |
|------|------|:---:|------|
| 语速 | 每分钟有效词数（正常 120-170 wpm） | 25 | 音频时长 + WhisperX 转写词数 |
| 停顿频率 | 长停顿（>0.5s）次数 / 分钟（正常 <5 次/分钟） | 20 | 音频 VAD 静音段检测 |
| 重复率 | 重复词数 / 总词数（正常 <5%） | 20 | 转写文本分析 |
| 语法正确性 | 语法错误数 / 总词数 | 20 | deepseek-v4-flash 语法检查 |
| 内容相关性 | 回复与场景上下文的语义匹配度 | 15 | deepseek-v4-flash 语义相似度 |

**综合流利度分数** = 五项加权求和（满分 100）

#### 分段评级

| 分数 | 等级 | 说明 |
|------|:---:|------|
| 85-100 | 优秀 | 表达流利，语速自然，极少停顿和重复 |
| 70-84 | 良好 | 偶有停顿和重复，但不影响交流 |
| 55-69 | 中等 | 停顿较多，有重复和自我修正 |
| 40-54 | 初级 | 频繁停顿，表达断断续续 |
| <40 | 入门 | 逐词拼凑，基本无法连贯表达 |

#### 输出形式

每轮对话后记录分数，对话结束后展示：

```
对话流利度报告
┌────────────────────────┐
│ 综合流利度：72（良好）  │
│                        │
│ 语速    ████████░░ 85  │
│ 停顿    ██████░░░░ 62  │
│ 重复    ████████░░ 78  │
│ 语法    ███████░░░ 70  │
│ 相关性  ██████░░░░ 65  │
│                        │
│ 本轮最佳：第 3 轮（85）│
│ 建议：减少句中停顿，   │
│ 尝试用连词串联表达     │
└────────────────────────┘
```

#### 与模块 6 的关系

```
模块 6 对话：每轮 { 用户语音 → 转写 → 流利度评估（模块 5）→ AI 生成回复 }
                                        │
                                        ▼
                                每轮结果静默存储
                                        │
                                        ▼
                            对话结束 → 汇总报告
```

流利度评估结果同时存入 `conversation_messages` 的 `fluency_scores` 字段。

#### 边界情况

| 场景 | 处理 |
|------|------|
| 用户回复 < 3 个词 | 评分但标注「回复过短，评估仅供参考」 |
| VAD 无法检测停顿 | 使用固定阈值 0.5s 兜底 |

| 某轮完全没有可评估内容 | 跳过该轮，不纳入汇总 |

#### 验收标准

- [ ] 模块 6 每轮对话自动触发流利度评估

### 模块 7：AI 语法纠错与润色 `P1`

#### 需求描述

嵌入模块 6 对话中，每轮对用户转写文本进行语法纠错和地道表达润色。展示原文与错误标注、修正版、语法说明，并提供更地道的替代表达。

#### 纠错维度

| 错误类型 | 示例原文 | 修正版 | 权重 |
|------|------|------|:---:|
| 时态错误 | I go there yesterday | I **went** there yesterday | 高 |
| 主谓一致 | He don't like it | He **doesn't** like it | 高 |
| 冠词遗漏/误用 | I saw dog in park | I saw **a** dog in **the** park | 中 |
| 介词错误 | I arrived at Monday | I arrived **on** Monday | 中 |
| 词序问题 | I very much like it | I like it **very much** | 低 |
| 单复数 | I have two cat | I have two **cats** | 中 |

#### 展示方式

对话气泡中展开展示：

```
原文：I go to the store yesterday and buy two apple.
     ~~~~~~                         ~~~~  ~~~~~
修正：I went to the store yesterday and bought two apples.

语法说明：
• go → went：过去时应用过去式
• buy → bought：并列动词同样保持过去式
• apple → apples：two 后接复数

地道表达 💡：
"I went to the store yesterday" 
→ 更自然 "I stopped by the store yesterday"
```

#### 润色方向

| 类型 | 原文 | 润色版 |
|------|------|------|
| 礼貌升级 | I want a coffee | I'd like a coffee |
| 口语自然化 | I am going to leave now | I'm gonna head out now |
| 俚语/习语 | I was very surprised | I was blown away |
| 缩略自然化 | I did not know that | I didn't know that |
| 冗余精简 | In my opinion, I think | I think |

润色版作为**可选建议**展示，不强制替换，用户可点击采纳。

#### 嵌入方式

```
模块 6 对话每轮流程：
  用户语音 → WhisperX 转写 → deepseek-v4-flash 语法检查 + 润色
                              │
                              ▼
                         纠错标注 + 润色建议
                              │
                              ▼
                         展示修正气泡（带折叠）
                              │
                              ▼
                         用户可展开查看 / 点采纳润色版
```

- 纠错**默认展示**在对话气泡右侧可展开区
- 润色建议**默认折叠**，点击「💡 更地道的说法」展开
- 用户采纳润色 → 记录行为，优化后续润色偏好

#### 记录

语法错误记录存入 `conversation_messages`：

```json
{
  "text": "I go to the store yesterday and buy two apple.",
  "grammar_check": {
    "errors": [
      {"word": "go", "correction": "went", "type": "tense", "position": [0, 2]},
      {"word": "buy", "correction": "bought", "type": "tense", "position": [6, 7]},
      {"word": "apple", "correction": "apples", "type": "plural", "position": [9, 10]}
    ],
    "polish_suggestion": "I stopped by the store yesterday and picked up two apples.",
    "polish_adopted": false
  }
}
```

#### 边界情况

| 场景 | 处理 |
|------|------|
| 原文无语法错误 | 不展示纠错区，显示 ✅「This sounds good!」 |
| 原文过短（< 3 词） | 不纠错，标注「回复太短，建议展开表达」 |
| 转写置信度低 | 先纠错，但标注「转写可能不准确，纠错仅供参考」 |
| deepseek-v4-flash 返回格式异常 | 展示原文，不展示纠错，记录日志 |
| 同一错误类型多次出现 | 对话结束汇总「你的常见错误 Top 3」 |

#### 验收标准

- [ ] 模块 6 每轮对话自动触发语法纠错
- [ ] 错误单词高亮 + 修正版 + 语法说明完整展示
- [ ] 6 种错误类型均能正确识别（人工验证 20 条）
- [ ] 润色建议折叠可展开，用户可点击采纳
- [ ] 无语法错误时不展示纠错区
- [ ] 对话结束汇总展示常见错误 Top 3

### 模块 8：情景角色扮演 `P2`

#### 需求描述

用户选择特定角色（面试者/服务员/导游），AI 扮演对方角色进行多轮互动。系统评估用户表达的**角色贴合度**——表达是否恰当、是否符合场景礼仪、专业术语是否正确。与模块 6 的区别：模块 6 侧重语言能力，模块 8 侧重场景应用能力。

#### MVP 角色

| 用户角色 | AI 角色 | 场景描述 | 典型话题 |
|------|------|------|------|
| 面试者 | 面试官 | 英文工作面试 | 自我介绍/项目经历/职业规划/优缺点/薪资期望 |
| 餐厅服务员 | 顾客 | 餐厅服务场景 | 迎宾引座/推荐菜品/处理忌口/结账/投诉应对 |
| 导游 | 游客 | 景点导览场景 | 景点介绍/历史文化/交通指引/餐饮推荐/应急处理 |

#### 对话流程

与模块 6 一致（语音→转写→生成→TTS），差异在以下两点：

**1. 角色设定注入 Prompt**：

```
你是{AI角色}，正在{场景描述}。
对方是{用户角色}，英语水平{CEFR等级}。
你的任务：
- 模拟真实{场景}中的对话
- 根据用户表达评估：礼节恰当性、专业术语、场景应对
- 对话结束后给出评分和改进建议
```

**2. 评分侧重不同**：

| 模块 6 评分维度 | 模块 8 评分维度 | 说明 |
|------|------|------|
| 发音准确率 30% | 角色贴合度 40% | 表达是否符合角色身份和场景 |
| 语法正确率 30% | 场景礼仪 25% | 敬语/称呼/语气是否得体 |
| 词汇丰富度 20% | 专业术语 20% | 场景相关词汇使用是否准确 |
| 对话参与度 20% | 应对能力 15% | 面对突发问题是否能恰当回应 |

### 模块 10：游戏化闯关学习 `P2`

#### 需求描述

通过每日闯关和配音挑战两种游戏化模式，配合积分勋章体系，激发用户学习兴趣和持续动力。不包含多人 PK/擂台（P3 阶段）。

#### 玩法一：每日闯关

用户每天跟读一组句子（5 句），闯关成功获得积分。

```
每日闯关：
┌────────────────────────────┐
│ 🏰 今日关卡               │
│                            │
│ 第 1 关 ★☆☆               │
│ "I'd like a cup of coffee" │
│ 🎤 跟读 → 发音评分 ≥ 70    │
│ ✅ 通过！+20 积分          │
│                            │
│ 第 2 关 ★★☆               │
│ ...                        │
│                            │
│ 第 5 关 ★★★               │
│ ...                        │
│                            │
│ 🎉 全部通过！额外 +30 积分  │
│ 今日获得：130 积分          │
└────────────────────────────┘
```

**闯关规则**：
- 5 关，难度递增（A1 → B2）
- 每关 1 句跟读，发音分 ≥ 70 通过，不通过可无限重试
- 每关通过 +20 积分，全通 +30 额外奖励
- 每日限 1 轮，次日刷新

#### 玩法二：配音挑战

用户给影视/动画片段配音，模仿原声的发音和语调。

**配音流程**：
1. 播放原声片段（10-20 秒，带字幕）
2. 用户配音录音
3. 系统对比原声和用户录音：发音相似度 + 语调相似度 + 情感匹配度
4. 展示配音结果 + 得分

**配音内容**：预录入 30 个经典片段（电影/动画/演讲），按难度分级。

| 难度 | 片段时长 | 数量 | 示例 |
|:---:|:---:|:---:|------|
| 简单 | 5-10s | 10 | 动画短句 "To infinity and beyond!" |
| 中等 | 10-15s | 10 | 电影台词 "Houston, we have a problem." |
| 困难 | 15-20s | 10 | 演讲片段 "I have a dream..." |

**配音评分**：

| 维度 | 权重 | 说明 |
|------|:---:|------|
| 发音相似度 | 50% | 音素级对比原声 |
| 语调相似度 | 30% | 基频曲线对比 |
| 情感匹配度 | 20% | deepseek-v4-flash 评估情感一致性 |

#### 积分体系

| 行为 | 积分 |
|------|:---:|
| 完成每日任务（每个） | +10 |
| 每日闯关全通 | +130 |
| 配音挑战完成 1 次 | +30 |
| 连续打卡 7 天 | +100 加成 |
| 发音单次 ≥ 85 分 | +20 加成 |
| 分享配音到社区 | +10 |

积分累计展示，不做排行榜（避免初期数据不足时冷清感）。

#### 勋章体系

| 勋章 | 获取条件 | 图标建议 |
|------|------|:---:|
| 🗓️ 新手上路 | 累计学习 7 天 | 日历 |
| 🔥 坚持之星 | 连续打卡 7 天 | 火焰 |
| 🎯 发音突破 | 发音分首次 ≥ 80 | 靶心 |
| 📈 进步达人 | 发音/流利度总分较上月提升 ≥ 10 | 上升箭头 |
| 🎬 配音达人 | 完成 10 次配音挑战 | 麦克风 |
| 💯 满分挑战 | 单次发音 ≥ 95 分 | 皇冠 |
| 🏆 学霸成就 | 累计学习 30 天 | 奖杯 |

勋章弹窗动画展示，获取时自动触发。

#### 边界情况

| 场景 | 处理 |
|------|------|
| 闯关重试 N 次仍不通过 | 第 3 次失败时提示「要不要先听标准音再试？」 |
| 配音片段含生僻词 | 播放前展示音标，支持先听后录 |
| 用户当天已完成闯关 | 显示「今日已完成，明天再来挑战」 |
| 积分为 0 的新用户 | 引导先完成任务获取积分 |

#### 验收标准

- [ ] 每日闯关 5 关难度递增，发音分 ≥70 通过
- [ ] 配音挑战 3 级难度各 ≥5 个片段可选

### 模块 13：学习效果预测与预警 `P2`

#### 需求描述

基于用户历史学习数据（发音分、流利度、学习时长），用线性回归预测达到目标水平所需时间。设定预警规则，在学习频率下降或进步停滞时主动推送提醒，帮助用户保持学习节奏。

#### 预测模型

**方法**：简单线性回归，Y 轴为综合分数，X 轴为学习天数。

```
输入数据：
  - 最近 30 天的综合分数（发音×0.4 + 流利度×0.3 + 语法×0.3）
  - 每日学习时长

输出：
  - 当前综合分：72
  - 趋势斜率：+0.35 分/天（上升）/ -0.10 分/天（下降）/ 0.02 分/天（持平）
  - 预计达标天数：当前目标分 85 → (85-72)/0.35 ≈ 37 天
```

**展示**：模块 12 进度页底部展示预测信息

```
┌──────────────────────────────┐
│ 🔮 学习预测                  │
│                              │
│  当前综合分：72              │
│  趋势：📈 每天 +0.35 分      │
│  距离目标 85 分预计还需 37 天│
│  按当前节奏，预计 7月5日 达成 │
│                              │
│  💪 继续保持！               │
└──────────────────────────────┘
```

**数据不足时的处理**：学习天数 < 7 天 → 显示「数据积累中，学习满 7 天后生成预测」

#### 预警规则

| 序号 | 触发条件 | 预警级别 | 提醒内容 |
|:---:|------|:---:|------|
| 1 | 连续 3 天未学习 | 📢 提示 | 「3 天没练习啦！每天 10 分钟，坚持就是进步」 |
| 2 | 本周时长较上周下降 >50% | 📢 提示 | 「这周学习时长变少了，抽空来练一练吧」 |
| 3 | 发音分连续 7 天未提升 | ⚠️ 关注 | 「发音分数停滞了，要不要试试我们的纠音专项练习？」 |

**提醒渠道**：系统内消息通知（P2 阶段不做邮件/短信/App Push）

#### 预警逻辑

```
每日凌晨定时任务（或用户登录时触发）：
  1. 查询所有活跃用户（近 30 天有学习记录）
  2. 逐一检查 3 条预警规则
  3. 命中 → 插入 notice 表 → 用户下次登录展示
```

#### 数据结构

```
learning_predictions
├── user_id
├── current_score: 当前综合分
├── trend_slope: 趋势斜率
├── target_score: 目标分数
├── predicted_days: 预计天数
├── predicted_date: 预计达成日期
└── updated_at

notices (通知)
├── user_id
├── type: prediction / alert / achievement
├── title
├── message
├── level: info / warning
├── read: false/true
└── created_at
```

#### 边界情况

| 场景 | 处理 |
|------|------|
| 学习数据 < 7 天 | 不生成预测，显示引导文案 |
| 趋势斜率为负 | 显示「近期有所回落，别灰心，调整节奏重新出发」 |
| 预测天数 > 365 | 不展示具体日期，提示「目标较远，建议将大目标拆分为小里程碑」 |
| 预警频繁触发 | 同一规则 7 天内不重复推送 |
| 用户关闭预警通知 | 支持在设置中关闭预警，但保留预测功能 |

#### 验收标准

- [ ] 学习满 7 天后正确生成线性回归预测
- [ ] 预测页面展示当前分、趋势方向、预计达标天数
- [ ] 3 条预警规则正确触发（3 天未学/时长下降/发音停滞）
- [ ] 同一规则 7 天内不重复推送
- [ ] 数据不足时显示引导文案，不报错
- [ ] 用户可关闭预警通知

### 3.1 项目定义

> 面向全年龄段用户，以 **AI 驱动的英语口语评测 + 情景对话为核心**，基于 NLP 和大语言模型技术，提供全天候个性化口语训练服务。

### 3.8 关键技术风险

| 风险 | 应对 |
|------|------|
| wav2vec2 本地推理延迟高 | 评估异步返回；GPU 加速；可降级为轻量模型版本 |
| deepseek-v4-flash 不稳定 | 超时降级预设回复，前端骨架屏+重试 |
| 豆包 TTS 合成失败 | 仅展示文字回复，标注「语音播放暂时不可用」 |

| 多年龄发音泛化差 | 初期聚焦 15-40 岁，儿童/老人用宽松阈值 |
| 1 人开发进度 | Phase 1 严格控范围，不做任何 P1 以下模块 |
