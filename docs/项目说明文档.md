# Lingolab — AI 驱动的英语口语训练系统

> 基于自然语言处理与大语言模型的智能英语口语训练平台，覆盖全年龄段用户，提供端到端语音交互、专业级发音评测与个性化学习路径。

---

## 一、项目实现业务的总体描述

### 1.1 项目背景

在全球化背景下，英语口语能力直接影响国际交流与职业发展。传统英语口语学习存在课堂时间有限、培训机构成本高昂、缺乏一对一指导等痛点，学习者难以获得随时随地的个性化口语训练。

Lingolab 通过 **ASR（语音识别）→ LLM（大语言模型）→ TTS（语音合成）** 端到端语音交互管线，结合 **wav2vec2 + GOP + CTC 强制对齐** 的专业级发音评测，构建了一套覆盖"测评定级 → 路径规划 → 内容推荐 → 效果预测"完整闭环的智能口语训练系统。

### 1.2 目标用户

系统面向全年龄段用户，覆盖以下人群：

| 用户群体 | 典型场景 | 学习目标 |
|----------|----------|----------|
| 儿童（6-12岁） | 趣味闯关、配音挑战 | 培养语感、基础发音 |
| 青少年（13-18岁） | 考试备考、跟读训练 | 中高考口语、CEFR 定级 |
| 大学生（19-25岁） | 学术讨论、面试模拟 | 四六级/雅思口语、职场准备 |
| 职场人士（26-50岁） | 商务谈判、会议交流 | 商务英语、行业术语 |
| 中老年（50岁以上） | 旅行出行、日常交流 | 基础口语、旅游英语 |

### 1.3 核心业务流程

```
用户注册 → 水平测评（自适应难度 + CEFR 定级）
    → 个性化学习路径规划（知识图谱 + NetworkX 拓扑排序）
    → 每日学习任务（AI 对话 / 发音跟读 / 角色扮演 / 语法纠错）
    → 学习进度可视化（雷达图 + 趋势折线图 + 热力图）
    → 学习效果预测与预警
```

### 1.4 核心技术链路

| 链路 | 技术方案 | 说明 |
|------|----------|------|
| **语音识别（ASR）** | WhisperX（small, int8） | 本地运行，词级时间戳 |
| **对话生成（LLM）** | 阿里百炼 DashScope（qwen-plus） | 对话生成 / 语法纠错 / 翻译 / 评分 |
| **语音合成（TTS）** | Edge TTS（微软，免费） | 4 种音色，SSML 控速，句级时间戳 |
| **发音评测** | wav2vec2 + GOP + CTC 强制对齐 | 音素级五维评分 |
| **G2P 映射** | g2p-en | 音素→音标映射 |
| **音频处理** | librosa + soundfile + pydub + ffmpeg | 特征提取 / 格式转码 |
| **ML 推理** | PyTorch（Apple Silicon MPS 加速） | torch + torchaudio |

### 1.5 六大核心竞争力

1. **端到端语音交互管线**：ASR → LLM → TTS 全链路本地完成，延迟可控，接近真人对话节奏
2. **专业级发音评测**：基于 wav2vec2 + GOP + CTC 强制对齐，从音素级别给出五维精细评分，比市面"跟读打分"更专业
3. **AI 驱动全链路个性化**：从测评定级 → 知识图谱路径规划 → 四因子推荐 → 效果预测，形成完整学习闭环
4. **全年龄段覆盖**：儿童到中老年，场景从日常交流到商务谈判，适用面广
5. **技术栈先进且成本可控**：LLM 用国产千问（成本低），TTS 用微软免费方案，ASR 和发音评测本地运行
6. **完整的教学管理生态**：覆盖 C 端学习者 + 教师端 + 运营端，具备 B 端商业化潜力

## 二、具体功能列表

系统共实现 **16 个功能模块**，覆盖学习、评估、激励、管理四大维度。

### 模块 1：用户注册与多维度画像

- **功能描述**：用户注册时采集年龄、英语水平（通过水平测试定级）、学习目标（日常交流/考试/商务）、学习偏好等信息，构建用户多维画像
- **技术实现**：JWT 注册/登录，bcrypt 密码加密，24h Token 有效期
- **画像维度**：年龄、当前水平、目标水平、学习目的、兴趣偏好、可用学习时间

### 模块 2：英语水平智能测评

- **功能描述**：提供听力、口语、阅读、语法四个维度的自适应测评，根据用户答题情况动态调整题目难度
- **技术实现**：自适应难度算法，CEFR 等级映射（A1-C2），口语题集成 ASR 评分
- **输出结果**：综合 CEFR 等级 + 各维度能力雷达图 + 短板分析

### 模块 3：个性化学习路径规划

- **功能描述**：基于用户画像和测评结果，为每位用户定制专属学习路径，每日自动推送学习任务
- **技术实现**：知识图谱 + NetworkX BFS/拓扑排序算法
- **任务类型**：单词学习、发音跟读、AI 对话、听力训练

### 模块 4：AI 发音评测与纠错

- **功能描述**：用户跟读标准发音，系统从五个维度精细评分，音素级波形对比可视化展示发音问题
- **技术实现**：wav2vec2 + GOP（Goodness of Pronunciation）+ CTC 强制对齐
- **五维评分**：音素准确度、重音、连读、语调、节奏 — 加权综合评分
- **纠错输出**：逐词发音评分 + 音素级错误标注 + 针对性纠音练习生成

### 模块 5：流利度与完整性评估

- **功能描述**：综合评估用户口语的流利度和内容质量
- **评估指标**：语速、停顿频率、重复率、自我修正率、回答完整性、内容相关性、语法正确性
- **实现方式**：集成在对话评分流程中，与发音评测协同输出综合口语能力评分

### 模块 6：智能语音对话练习

- **功能描述**：AI 虚拟对话伙伴，支持 8 个真实场景的沉浸式自由对话练习
- **技术实现**：ASR（WhisperX）→ LLM（千问）→ TTS（Edge TTS）完整管线，SSE 流式传输
- **场景覆盖**：餐厅点餐、酒店入住、商务谈判、学术讨论、旅行出行、医院就诊、机场出行、学校场景
- **智能特性**：AI 根据用户水平自动调整语速和用词难度，支持话题自由切换

### 模块 7：AI 语法纠错与润色

- **功能描述**：实时识别口语表达中的语法错误并给出纠正版本，同时提供更地道的表达推荐
- **技术实现**：LLM 语法纠错 + 润色建议生成
- **纠错类型**：时态、主谓一致、冠词、介词搭配、句式结构
- **交互方式**：支持语音输入 + 文本输入双模态

### 模块 8：情景角色扮演

- **功能描述**：选择角色与 AI 进行多轮互动角色扮演，系统实时评价表达恰当性
- **角色类型**：面试者、服务员、导游、医生、商务人士、学生、顾客、酒店前台
- **评分维度**：角色贴合度、语言恰当性、流利度、语法准确性（四维评分）

### 模块 9：学习资料智能推荐

- **功能描述**：基于用户兴趣偏好、学习记录和能力短板，精准推荐学习材料
- **技术实现**：知识图谱四因子评分推荐算法
- **推荐因子**：难度匹配度、兴趣相关性、能力短板覆盖、学习进度适配
- **资源类型**：视频、音频、文章、练习题

### 模块 10：游戏化闯关学习

- **功能描述**：通过游戏化机制激发学习兴趣和持续学习动力
- **功能子项**：
  - **每日闯关**：语音挑战关卡，逐级提升难度
  - **配音挑战**：为影视片段配音，系统评分排名
  - **积分系统**：完成任务获得积分，累计升级
  - **勋章墙**：达成里程碑解锁成就勋章

### 模块 11：学习社区与社交互动

- **功能描述**：内置学习社区，支持用户间互动和互助学习
- **功能子项**：
  - **语音挑战广场**：发起/参与语音挑战，AI 辅助评分
  - **讨论区**：话题讨论、经验分享
  - **学习小组**：创建/加入小组，组队学习
  - **排行榜**：积分排行、挑战排行

### 模块 12：学习进度可视化追踪

- **功能描述**：以可视化图表展示多维度学习进步轨迹
- **图表类型**：
  - **雷达图**：多维度能力分布（发音/流利度/语法/词汇/听力）
  - **趋势折线图**：各维度历史得分变化趋势
  - **日历热力图**：每日学习时长/活跃度
  - **统计卡片**：累计学习天数、总时长、完成练习数

### 模块 13：学习效果预测与预警

- **功能描述**：基于历史数据预测学习效果，及时发现学习风险
- **技术实现**：线性回归预测模型 + 3 条预警规则
- **预警规则**：连续学习时长下降、练习完成率低于阈值、预测进度落后于目标
- **输出**：预计达到目标水平的时间 + 风险等级 + 改进建议

### 模块 14：教师端教学管理后台

- **功能描述**：教师管理班级和学生，布置和点评作业
- **功能子项**：
  - **班级管理**：创建/管理班级、添加/移除学生
  - **作业布置**：布置定制化口语作业（跟读/对话/角色扮演）
  - **提交点评**：查看学生作业录音，在线评分和点评
  - **学生报告**：查看学生能力雷达图、进步趋势、薄弱点分析

### 模块 15：运营管理后台

- **功能描述**：平台运营人员管理用户、内容和平台数据
- **功能子项**：
  - **用户管理**：查看/禁用/删除用户账号
  - **内容管理**：管理学习资源、配音素材、挑战题库（CRUD）
  - **数据仪表盘**：DAU/MAU、留存率（D1/D7）、付费转化率
  - **操作日志**：管理员操作记录审计

### 模块 16：智能客服与帮助系统

- **功能描述**：7×24 小时智能客服，解答用户问题
- **技术实现**：LLM 智能问答 + 问题分类 + 转人工机制
- **交互方式**：支持语音和文字双模态交互
- **问题分类**：产品使用、课程选择、技术问题、账户问题、其他

