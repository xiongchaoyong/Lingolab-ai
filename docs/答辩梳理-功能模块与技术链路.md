## 一、系统总体架构

### 1.1 技术架构

```
前端（Vue 3 + Vite + Pinia）
        ↕  HTTP / SSE（流式）
后端（FastAPI + Python）
        ↕
┌───────────────────────────────────────────────┐
│  AI 服务层（核心能力）                          │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐       │
│  │ ASR 语音  │ │ LLM 大语言│ │ TTS 语音 │       │
│  │ 识别      │ │ 模型对话  │ │ 合成     │       │
│  │ WhisperX  │ │ DashScope│ │ Edge TTS │       │
│  └──────────┘ └──────────┘ └──────────┘       │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐       │
│  │ 发音评测  │ │ 流利度    │ │ 知识图谱 │       │
│  │ wav2vec2  │ │ ASR+LLM  │ │ NetworkX │       │
│  └──────────┘ └──────────┘ └──────────┘       │
└───────────────────────────────────────────────┘
        ↕
数据库（MySQL 8）
```

### 1.2 项目分工

| 层次 | 技术栈 | 说明 |
|------|--------|------|
| 前端 | Vue 3.5 + Vite 8 + Pinia 3 + Vue Router 4 | 组件化 SPA，状态管理，路由守卫 |
| 后端 | Python + FastAPI + Uvicorn | 异步高性能 API 框架 |
| 数据库 | MySQL 8 + SQLAlchemy + Alembic | ORM 映射，迁移管理 |
| AI引擎 | WhisperX / wav2vec2 / DashScope / Edge TTS | 语音识别 / 发音评测 / 大模型 / 语音合成 |
| 知识图谱 | NetworkX + MySQL | 内存图遍历 + 关系持久化 |

### 1.3 启动时预加载

后端 `main.py` 在服务启动时通过 `lifespan` 机制预加载：
1. **知识图谱**：从 MySQL 全量加载节点/边到 NetworkX 有向图
2. **发音评测模型**：加载 wav2vec2 + G2P 音素转换器
3. **WhisperX 模型**：加载 small 模型用于 ASR 和强制对齐
4. **TTS调用api**

### 模块 1：用户注册与多维度画像

**业务功能**：
- 用户注册时采集：用户名、邮箱、密码、年龄、年龄段（儿童/青少年/大学生/职场/中老年）、学习目标（日常交流/考试/商务/出国/兴趣爱好）、兴趣标签
- 支持三种角色：learner（学习者）、teacher（教师）、admin（管理员）
- JWT Token 认证，密码 bcrypt 加密存储

**技术实现**：
- 后端：`app/api/auth.py` 路由 + `app/core/security.py` JWT 生成/验证
- 数据库：`user_profiles` 表，包含 `level_self`（自评等级）、`level_test`（测评等级）、`level_final`（最终等级）
- 密码哈希：`passlib` 库 bcrypt 算法
- Token：`python-jose` 生成 JWT，过期时间可配置

**数据链路**：
```
前端注册页 → POST /api/auth/register → 校验唯一性 → bcrypt 加密密码 → 写入 user_profiles → 返回 JWT
前端登录页 → POST /api/auth/login → 验证密码 → 生成 JWT → 返回 token + 用户信息
```

**数据库表**：`user_profiles`（20+ 字段，含多维度画像数据）

### 模块 2：英语水平智能测评

**业务功能**：
- 四维度测评：听力理解、口语表达、阅读理解、语法选择
- 自适应难度：根据用户答题情况动态调整下一题难度
- CEFR 定级：根据综合得分映射到 A1-C2 六个等级
- 测评完成后自动更新用户画像中的 `level_test` 和 `level_final`

**技术实现**：
- 后端：`app/api/assessment.py`（测评路由）+ `app/models/assessment.py`（题目/记录模型）
- LLM 评分：口语题通过 WhisperX 转写后，由 DashScope LLM 进行四维度评分（内容相关性/语法/词汇/连贯性，各 0-25 分，总分 100）
- 自适应算法：根据当前正确率调整下一题难度等级
- 题库存储：`assessment_questions` 表，按维度和难度分类

**数据链路**：
```
用户开始测评 → GET /api/assessment/start → 创建 session → 返回第一题
用户答题 → POST /api/assessment/answer → 记录答案 → 计算得分 → 自适应选下一题
口语题 → 前端录音 → 音频上传 → WhisperX 转写 → LLM 四维评分
测评完成 → POST /api/assessment/complete → CEFR 定级 → 更新 user_profiles.level_test
```

**数据库表**：`assessment_questions`（题库）、`assessment_records`（答题记录）

### 模块 3：个性化学习路径规划

**业务功能**：
- 基于用户画像和测评结果，利用知识图谱为用户定制专属学习路径
- 每日自动推送学习任务（跟读/对话/听力三种类型）
- 六步图遍历算法：短板优先 → 目标加权 → CEFR 匹配 → 前置依赖 → 兴趣优选 → 写入任务

**技术实现**：
- 知识图谱：`app/services/knowledge_graph.py` — NetworkX 有向图，节点类型包括 `skill`（技能）、`material`（资料）、`topic`（场景）、`cefr_level`（等级），边类型包括 `HAS_PREREQ`（前置依赖）、`TEACHES`（教授）、`COVERS`（覆盖）、`BELONGS_TO`（归属）、`SIMILAR_TO`（相似）
- 推荐服务：`app/services/recommendation.py` — 短板分析 + 三因子评分（短板匹配 40% + 难度匹配 35% + 兴趣匹配 25%）
- 每日任务：`DailyTask` 模型，支持 pending/completed/skipped 状态
- 任务操作：支持跳过（skip）、替换（replace）、调整难度（±1 CEFR 级别）

**数据链路**：
```
用户登录 → GET /api/learning-path/today → 检查今日任务
  ├─ 无任务 → 自动生成 3 个任务（跟读+对话+听力）
  └─ 有任务 → 返回任务列表
用户完成任务 → POST /api/learning-path/complete → 记录完成 + 更新进度
推荐资料 → GET /api/recommendations/materials → 三因子评分排序 → 返回视频/文章/音频各 2 篇
```

**核心算法 — 每日任务生成六步图遍历**：
1. **短板优先**：从 `UserSkillScore` 动态分数中取最低分维度
2. **目标加权**：学习目标映射场景偏好（如"商务"→ 面试/会议场景）
3. **CEFR 匹配**：图查找 `BELONGS_TO` 同等级内容
4. **前置依赖**：检查技能前置是否已掌握（`HAS_PREREQ` 边）
5. **兴趣优选**：资料标签 ∩ 用户兴趣
6. **写入任务**：3 条记录写入 `daily_tasks` 表

### 模块 4：AI 发音评测与纠错

**业务功能**：
- 用户跟读单词或句子，系统进行五维度精细评分
- 五维度：音素准确度、重音位置、语调曲线、连读表现、节奏感
- 音素级纠错建议：低分音素自动匹配发音技巧提示
- 可视化数据：音素能量图、语调 F0 曲线、连读词对间隙

**技术实现**：
- 核心服务：`app/services/pronunciation.py` — wav2vec2 + CTC 强制对齐 + GOP 算法
- 模型：`torchaudio.pipelines.WAV2VEC2_ASR_BASE_960H`（960 小时 LibriSpeech 预训练）
- G2P 转换：`g2p-en` 库将文本转为 ARPABET 音素序列
- CTC 强制对齐：自实现 Viterbi 动态规划算法，在 wav2vec2 输出的对数后验概率上做音素级对齐
- GOP 评分：Goodness of Pronunciation，基于对齐后音素帧的平均对数概率计算
- 重音分析：`librosa` 提取 RMS 能量包络，计算能量变异系数（CV）
- 语调分析：`librosa.pyin` 提取 F0 基频，拟合线性趋势，判断升降调
- 连读分析：WhisperX 词级时间戳 + G2P 辅元判断，计算词间间隙
- 节奏分析：CTC 对齐的音素时长分布，变异系数 + 异常停顿检测

**五维评分权重**：
- 单词模式：音素准确度 50% + 重音位置 25% + 节奏感 25%
- 句子模式：音素准确度 40% + 重音位置 15% + 连读表现 15% + 语调曲线 15% + 节奏感 15%

**数据链路**：
```
前端录音 → 音频上传（WAV 16kHz）
  → wav2vec2 提取特征（对数后验概率）
  → G2P 文本→音素
  → CTC 强制对齐（Viterbi DP）
  → GOP 音素评分
  → 重音分析（RMS 能量）
  → 语调分析（F0 基频）
  → 连读分析（WhisperX 词级时间戳）
  → 节奏分析（音素时长分布）
  → 五维加权综合分
  → 返回评测结果 + 可视化数据
```

**异步处理**：发音评测通过 `ThreadPoolExecutor` 在线程池中运行，避免阻塞 FastAPI 事件循环

### 模块 5：流利度与完整性评估

**业务功能**：
- 五维评分体系：语速（WPM）、停顿频率、重复率、语法正确性、内容相关性
- 前三维度由算法计算，后两维度由 LLM 评估
- 分段评级：85-100 优秀 / 70-84 良好 / 55-69 中等 / 40-54 初级 / <40 入门

**技术实现**：
- 算法部分：`app/services/fluency.py`
  - 语速：单词数 / 说话时长（分钟），理想范围 100-120 WPM
  - 停顿：词间间隙 > 0.5 秒计为停顿，< 2 次/分钟满分
  - 重复：连续重复词 + 2-gram 重复检测，< 5% 满分
- LLM 部分：`LLMService.score_fluency()` — 逐轮评估语法正确性和内容相关性
- 多轮汇总：各轮取平均，标出最佳轮次

**数据链路**：
```
对话过程中累积用户发言 → 对话结束后触发评估
  → WhisperX 词级时间戳 → 算法计算语速/停顿/重复
  → LLM 评估语法/相关性
  → 五维汇总 → 返回综合流利度分数
```

### 模块 6：智能语音对话练习

**业务功能**：
- AI 虚拟对话伙伴，支持 4 大场景：自我介绍、问路、购物、餐厅
- AI 根据用户 CEFR 等级自动调整语速和用词难度
- 支持 SSE 流式输出，逐 token 返回 AI 回复，实时显示
- 对话结束后三维度评分：语法准确性、词汇丰富度、参与度

**技术实现**：
- ASR：WhisperX small 模型，int8 量化，CPU 推理
- LLM：阿里百炼 DashScope API，模型 `qwen-plus`，温度 0.9
- TTS：Edge TTS（微软免费），4 种音色可选
- 场景 Prompt：每个场景有独立的 System Prompt，注入 CEFR 等级指令
- 流式输出：SSE（Server-Sent Events），前端 EventSource 接收

**四场景 Prompt 设计**：
| 场景 | AI 角色 | 用户角色 |
|------|---------|---------|
| self_intro | 友好的对话伙伴 Alex | 做自我介绍的人 |
| directions | 迷路的游客 | 当地人指路 |
| shopping | 服装店店员 | 顾客 |
| restaurant | 餐厅服务员 | 用餐顾客 |

**CEFR 难度自适应**：
| 等级 | AI 语言要求 |
|------|------------|
| A1 | 极简词汇，短句，慢速 |
| A2 | 简单日常词汇，短句清晰 |
| B1 | 中级词汇，可用短语动词和习语 |
| B2 | 高级词汇自然使用，正常语速复杂句 |

**数据链路**：
```
用户选择场景 → 前端录音 → 音频上传
  → ASR（WhisperX）→ 语音转文字
  → LLM（DashScope qwen-plus）→ 生成 AI 回复（SSE 流式）
  → TTS（Edge TTS）→ 合成 AI 语音
  → 前端播放 AI 语音 + 显示文字
  → 多轮循环...
  → 对话结束 → LLM 三维度评分
  → 保存对话记录到 conversation_sessions / conversation_messages
```

**数据库表**：`conversation_sessions`（会话）、`conversation_messages`（消息）

### 模块 7：AI 语法纠错与润色

**数据链路**：
```

```

### 模块 13：学习效果预测与预警

**业务功能**：

  1. 连续 3 天未学习

**技术实现**：
- 后端：`app/services/prediction.py`

- 趋势判断：slope > 0.05 上升，< -0.05 下降，否则稳定
- 持久化：预测结果写入 `learning_predictions` 表
- 通知：`notices` 表，支持 prediction/alert/achievement 三种类型

**数据链路**：
```
GET /api/prediction

  → 预测达标天数

```

## 三、核心 AI 技术链路详解

### 3.1 语音对话完整链路（模块 6 核心）

```
[前端] 录音 → WebM/PCM 音频
        ↓
[ASR] WhisperX small (int8, CPU)
  → 转录 + 词级时间戳 + 置信度
        ↓
[LLM] 阿里百炼 DashScope (qwen-plus)
  → System Prompt（场景+角色+CEFR等级）
  → 对话历史（最近10轮）
  → 流式生成回复 (SSE)
        ↓
[TTS] Edge TTS (微软免费)
  → 4种音色可选 (JennyNeural/GuyNeural/AriaNeural/DavisNeural)
  → 合成 MP3 音频
        ↓
[前端] 播放 AI 语音 + 显示文字
        ↓
[评分] LLM 三维度评分 (语法/词汇/参与度)
```

### 3.2 发音评测完整链路（模块 4 核心）

```
[前端] 录音 → WAV 16kHz 单声道
        ↓
[wav2vec2] 提取对数后验概率 (log_softmax)
        ↓
[G2P] 文本 → ARPABET 音素序列
        ↓
[CTC 强制对齐] Viterbi 动态规划
  → 音素级时间对齐结果
        ↓
[GOP 评分] exp(平均对数概率) × 100
  → 音素准确度
        ↓
[重音分析] librosa RMS 能量包络
  → 能量变异系数 → 重音评分
        ↓
[语调分析] librosa pyin F0 基频
  → 线性趋势拟合 → 升降调判断 → 语调评分
        ↓
[连读分析] WhisperX 词级时间戳 + G2P 辅元判断
  → 词间间隙 → 连读评分
        ↓
[节奏分析] CTC 音素时长分布
  → 变异系数 + 异常停顿 → 节奏评分
        ↓
[综合] 五维加权 → 最终分数
```

### 3.3 个性化推荐链路（模块 3+9 核心）

```
[用户画像] 年龄段 + 学习目标 + CEFR 等级 + 兴趣标签
        ↓
[短板分析] UserSkillScore EMA 动态分数 → 最低维度
        ↓
[知识图谱遍历]
  ├── 短板维度 → 关联技能节点
  ├── CEFR 等级 → BELONGS_TO 边过滤
  ├── 学习目标 → 场景偏好映射
  └── 兴趣标签 → 资料标签匹配
        ↓
[三因子评分]
  ├── 短板匹配 (40%): 资料→TEACHES→技能∈短板?
  ├── 难度匹配 (35%): |资料CEFR - 用户CEFR|
  └── 兴趣匹配 (25%): 资料标签 ∩ 用户兴趣
        ↓
[输出] 视频×2 + 文章×2 + 音频×2
```

## 六、项目亮点总结（答辩用）

### 6.1 技术亮点

1. **多模型协同**：ASR（WhisperX）+ LLM（DashScope）+ TTS（Edge TTS）+ 发音评测（wav2vec2）四引擎协同，构建完整语音交互链路
2. **音素级发音评测**：自实现 CTC 强制对齐 Viterbi 算法 + GOP 评分，达到音素粒度的精准评测
3. **五维发音评分体系**：音素准确度 + 重音 + 语调 + 连读 + 节奏，多维度全面评估口语能力
4. **知识图谱驱动的个性化**：NetworkX 有向图建模技能/资料/场景关系，六步图遍历生成个性化学习路径
5. **SSE 流式对话**：大模型回复逐 token 返回，用户可实时看到 AI 回复，体验接近真人对话
6. **自适应难度**：测评和对话场景均支持 CEFR A1-C2 六级难度自适应

### 6.2 业务亮点

1. **全年龄段覆盖**：从儿童到中老年，不同年龄段有不同的学习目标和内容推荐
2. **16 模块完整闭环**：从注册→测评→学习→练习→评估→预测→社区→管理，功能完整
3. **游戏化激励**：积分、勋章、配音挑战，多维度激发学习动力
4. **社区互动**：语音挑战广场、讨论区、学习小组，社交化学习
5. **教师管理**：班级管理、作业布置、学生报告，支持 B 端教学场景

### 6.3 工程亮点

1. **前后端分离**：Vue 3 SPA + FastAPI RESTful API，职责清晰
2. **服务层抽象**：AI 能力封装为独立服务（ASR/LLM/TTS/Pronunciation），可独立替换升级
3. **全局单例模式**：模型预加载 + 单例管理，避免重复加载
4. **异步架构**：FastAPI 异步接口 + 线程池执行计算密集任务，不阻塞事件循环
5. **Pydantic 校验**：所有接口请求/响应均有 Schema 校验，类型安全
