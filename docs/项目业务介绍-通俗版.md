# Lingolab 项目业务介绍（通俗版）

> 用最直白的语言，讲清楚这个系统做了什么、为谁做、怎么串起来的。

---

## 一、这个系统是干什么的？

Lingolab 是一个**AI 英语口语训练平台**。你可以把它想象成一个"口袋里的外教"——

- 它能**听懂**你说英语（语音识别）
- 它能**告诉你哪里不对**（发音纠错、语法纠正）
- 它能**跟你对话**（AI 对话练习）
- 它能**记住你的水平**，越练越懂你（动态画像）

系统服务三类人：**学习者**（C端）、**教师**（B端）、**运营人员**（管理端）。

---

## 二、三条线怎么串起来？

把整个系统想象成一家**线上线下结合的英语培训机构**：

```
学习者来了 → 做入学测试 → 分配课程 → 每天上课练习
                                    ↓
教师 → 开班 → 布置作业 → 批改点评 → 看学生进步情况
                                    ↓
运营 → 看数据报表 → 管用户 → 管内容 → 维护智能客服知识库
```

三条线不是孤立的，而是**数据互通**的：
- 学习者的练习数据 → 教师能看到，用来针对性布置作业
- 学习者的活跃数据 → 运营能看到，用来调整运营策略
- 教师的班级作业数据 → 运营也能看到，用来评估平台健康度

## 三、核心主线：学习者的完整旅程（重点）

这是整个系统最核心的业务闭环。我们用一个叫"小明"的虚拟用户，从头走一遍。

### 阶段一：入门（一次性，~5 分钟）

#### 第 1 步：注册

小明打开网站，注册账号。需要填的信息很简单：

| 必填项 | 为什么需要 | 用来做什么 |
|--------|-----------|-----------|
| 用户名 + 密码 | 登录凭证 | 创建账号 |
| 年龄 | 系统自动映射成年龄段 | 儿童和成人看到的界面、推荐内容都不一样 |
| 学习目标 | 五选一（日常/考试/商务/旅行/兴趣） | 决定了推荐什么场景的练习 |
| 兴趣标签 | 勾选感兴趣的话题 | 推荐资料时优先匹配 |

填完这些，小明的**初始画像**就建好了。这个画像分两半：
- **静态部分**（不变）：年龄、学习目标、兴趣爱好
- **动态部分**（会变）：英语水平等级、各维度分数——这些刚开始是空的，要靠后面的测评来填充

#### 第 2 步：水平测评（必做，不可跳过）

注册完会自动跳转到测评页。测评的特点是**自适应**——不是固定 10 道题，而是：

```
答对一道 → 下一题变难 0.5 级
答错一道 → 下一题变简单 0.5 级
```

难度从 A1（零基础）到 C2（母语水平）动态浮动。题目包含：
- 听力选择题（放录音，选答案）
- 阅读选择题（读短文，选答案）
- 口语录音题（真的开口说，AI 语音识别后打分）

10 道题做完，系统给出三样东西：
1. **CEFR 等级**（A1 到 C2 之一），比如 B1
2. **雷达图**（发音、语法、词汇、流利度四个维度各有几分）
3. **弱项诊断**（最需要补什么）

这个测评结果就是后续所有推荐的**起点**。

---

### 阶段二：每天的学习循环（核心闭环）

测评完，小明每天打开首页，看到的是这样：

```
📊 学习概览
   已坚持 15 天 · 累积学习 8 小时 · 完成 42 个练习

📋 今日推荐任务
   ☐ 跟读练习 — "Ordering at a Restaurant"
   ☐ 情景对话 — 餐厅点餐场景
   ☐ 语法纠错 — 现在完成时
   ☐ 词汇学习 — 餐饮相关词汇
```

这四个任务是**系统根据小明的画像自动生成的**，逻辑是：

```
找出小明最差的能力维度（比如语法只拿了 42 分）
        ↓
匹配当前 CEFR 等级（B1，不能太难也不能太简单）
        ↓
结合学习目标（考试→多推学术场景）和兴趣（科技→推科技话题）
        ↓
检查知识图谱前置依赖（虚拟语气需要先学过去时，不能跳级）
        ↓
去重（最近 7 天推过的不重复推）
        ↓
生成 4 个任务
```

任务不强制的——可以跳过、换一个、调难度。

#### 核心练习 ①：AI 语音对话

小明打开"情景对话"，选择"餐厅点餐"场景：

```
🤖 AI：「Good evening! Welcome to our restaurant. 
       How many people are in your party tonight?」

🎤 小明（录音）：「Hi, just me. Can I get a table by the window?」

# 系统处理过程（用户无感知）：
# 录音 → 语音转文字（WhisperX）→ LLM理解并生成回复 
# → 同时做语法纠错 + 中文翻译 → TTS 把回复读出来

🤖 AI：「Of course! Right this way. Here's a nice table 
       by the window with a view.」

📝 实时提示：语法正确 ✓ ｜ 翻译："当然！这边请..."
```

聊了几轮后结束对话。系统给出**综合评分**：

| 维度 | 分数 | 说明 |
|------|------|------|
| 发音 | 72 | 整体不错，"restaurant"发音需注意 |
| 语法 | 58 | 时态错误较多，如"I go"应为"I went" |
| 词汇 | 75 | 用词恰当，但偏简单 |
| 流利度 | 80 | 语速自然，停顿合理 |

**关键来了**——这些分数不会看完就没了，而是被"吃"进一个叫**动态画像**的东西。

#### 画像更新引擎（EMA 算法）

每次练习后，系统自动做一件事：

```
新分数 × 30% + 历史平均 × 70% = 新的画像分数
```

什么意思呢？拿小明的语法来举例子：

```
之前语法的画像分数是 62 分
这次对话语法只拿了 58 分
新的画像分数 = 58 × 0.3 + 62 × 0.7 = 60.8 分
```

这个算法就像"算平时成绩"——一次考砸不会全崩，一次爆发也不会瞬间飞升。只有持续进步，画像才会稳定上升。

#### 核心练习 ②：发音评测

小明打开"跟读练习"，选一句话：

```
📢 标准发音：「The quick brown fox jumps over the lazy dog.」
🎤 小明跟读录音
⏳ 系统分析中...

📊 评分结果：
   音素准确度  78%  ⬤⬤⬤⬤⬤⬤⬤⬤○○
   重音位置    85%  ⬤⬤⬤⬤⬤⬤⬤⬤⬤○
   连读表现    62%  ⬤⬤⬤⬤⬤⬤○○○○
   语调曲线    70%  ⬤⬤⬤⬤⬤⬤⬤○○○
   节奏感      88%  ⬤⬤⬤⬤⬤⬤⬤⬤⬤○

🔴 错误高亮：
   "th" in "the" → 发音接近 "z"，舌头应放在上下齿之间
   "j" in "jumps" → 发音偏 "ch"，应发 /dʒ/
```

系统精确到每个音素打分，用红色标出读错的地方，并告诉你怎么纠正。

### 阶段四：辅助功能（保持动力）

除了核心的对话和发音练习，还有：

- **游戏化闯关**：每日 5 关 + 配音挑战，完成得积分，积分上排行榜
- **学习社区**：语音挑战广场（发自己的录音让大家听）、讨论区、学习小组
- **语法纠错**：输入一句话，AI 帮你找出错误并润色
- **资料推荐**：根据弱项和兴趣推荐视频/文章/音频
- **智能客服"小语"**：问产品问题或学习建议，AI 即时回答

## 四、教师端：管班、布置作业、点评学生

### 教师每天做什么？

**1. 创建班级**
```
老师王老师 → 创建"初级英语 A 班" → 系统生成邀请码 LINGO-XXXXXX
→ 学生输入邀请码加入 → 班级里就能看到所有学生的列表
```

**2. 布置作业**
```
王老师 → 选"布置作业" → 选班级 + 填标题"求职面试对话练习"
       → 选练习类型"情景对话" → 发布
→ 所有学生收到作业通知
```

**3. 批改点评**
```
学生提交语音作业 → AI 自动预评分（给老师参考）
                 → 王老师听录音 → 调整分数 → 写文字点评"你的发音进步很大，但面试时语气可以更自信一些"
→ 学生看到反馈
```

**4. 查看学生报告**
```
王老师点开某个学生 → 看到雷达图 + 趋势图 + 薄弱点分析
→ 发现班上大部分学生"连读"这个维度偏低
→ 下次课重点讲连读，作业也布置跟读练习
```

### 教师端的定位

教师不是替代 AI，而是**在 AI 基础上加温度**。AI 做初评提高效率，教师做终评提供专业判断和鼓励。

## 五、运营端：看数据、管用户、管内容

### 运营每天看什么？

**1. 数据仪表盘（一眼看全局）**

```
📊 用户规模          📊 学习活跃           📊 运营概况
   总用户：1,234        今日对话：89 次       老师数：15 人
   日活 DAU：210        今日跟读：156 次      班级数：23 个
   日新增：18 人         任务完成率：67%       总积分：89,200
```

还有 4 张图表：DAU 趋势折线图、CEFR 分布饼图、用户增长趋势、练习类型分布。运营可以快速判断平台是否健康。

**2. 用户管理**
```
搜索用户 → 按角色筛选（学生/教师/管理员）
→ 查看某个用户详情（画像、积分、各维度分数）
→ 禁用违规账号 / 把活跃学生升级为教师
→ 所有操作记录到日志，可追溯
```

**3. 内容与知识库管理**
```
维护智能客服的知识库文档
→ 文档自动向量化存入知识库
→ 用户提问时 AI 能从文档中找答案
→ 检索日志可监控用户都在问什么
→ 发现高频问题没覆盖 → 补充知识库
```

## 七、核心亮点（非技术人员也能看懂）

| 亮点 | 通俗解释 |
|------|----------|
| **越练越懂你** | 每次练习后系统自动更新你的能力画像，下次推荐更匹配的任务 |
| **真人般的对话** | 跟 AI 说话，2 秒内回复，还能实时纠正语法错误 |
| **精确到每个音** | 不是笼统打分，而是告诉你具体哪个音发错了、舌头该放哪 |
| **全年龄段** | 儿童到中老年，一套系统覆盖，推荐策略各不相同 |
| **三端打通** | 学生练 → 教师评 → 运营管，不是三个孤岛 |
| **成本很低** | API 用国产大模型，其他跑本地，全栈月费约 15 元 |
